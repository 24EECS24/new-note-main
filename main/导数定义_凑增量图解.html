导数定义题：别被绕晕，只有一个动作——「凑增量」

把“换元 / 改条件 / 单向 / 双向”全部忘掉，做题只需要下面这一条主线。

钥匙导数定义的唯一模板

f ′(x₀) = 增量→0 f(x₀ + 增量) − f(x₀) 增量
唯一要求：分子里 x₀ 旁边加的东西，和分母，必须是同一个「增量」，并且这个增量 → 0。

原题三步走，机械操作

Δx→0 f(x₀ − 2Δx) − f(x₀) Δx
第1步
找增量：看分子 x₀ 旁边是谁 —— 是 −2Δx，它才是真正的增量 h。
第2步
凑分母：分母现在是 Δx，把它也变成 −2Δx，外面乘 −2 配平：
= −2 · Δx→0 f(x₀ − 2Δx) − f(x₀) − 2Δx
第3步
套模板：Δx→0 时，增量 −2Δx 确实 → 0 ✓，所以这个分式就是 f ′(x₀)：
= −2 · f ′(x₀)
你问「为什么 lim 下面写 Δx→0，而不是 −2Δx→0？」
因为 Δx 是题目原本的变量，−2Δx 只是它的一个表达式。你愿意换元令 h = −2Δx、把下面写成 h→0 也完全对—— Δx→0 和 −2Δx→0 是同一个趋近过程，写哪个都不算错，纯粹是写法习惯。

结论「只要增量能 → 0 就行」——你是对的

已知 f ′(x₀) 存在时，增量 h 想写成什么都可以，只要 Δx→0 时它跟着 →0：
增量 h 写成Δx→0 时 h 是否 →0能否套模板
h = −2Δx是✓
h = Δx²是✓
h = Δx³是✓
h = sinΔx是✓
为什么单向就够？「f ′(x₀) 存在」本身的含义就是： 增量 h 无论从左边、右边、以什么速度、走哪条路径趋于 0，这个商全部收敛到同一个数 f ′(x₀)。 既然条条大路都到同一个值，你随便挑一条会 →0 的路（−2Δx、Δx²……）当然都得到它——不需要可逆，不需要双向。

澄清之前那个 |h|/h 反例，为什么跟本题无关

反例的前提：|h|/h 的双侧极限本来就不存在（左边 −1、右边 +1，对不上）。 极限都不存在，换个趋近条件，值当然可能变——它说明的是“极限不存在时别乱换条件”。
做题的前提：题目里 f ′(x₀) 存在且唯一，左右早已相等。 前提根本不同，反例打不到这道题。可以直接忘掉它，不必再纠结 h→0⁺。
做题口诀：找增量 → 分母凑成同一个增量 → 乘系数配平 → 增量趋于 0 就套 f ′(x₀)
增量怎么写都行，只要它 →0；单向足够，双向 / 可逆都不是你需要操心的事。
