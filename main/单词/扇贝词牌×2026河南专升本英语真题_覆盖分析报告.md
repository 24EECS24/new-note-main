# 扇贝单词牌组 × 2026 年河南专升本公共英语真题：词汇覆盖与估分报告

> 数据来源：`单词_全部内容.md`（扇贝共享笔记导出，编号 1–2329 连续）与 `2026年河南专升本公英真题回忆版.pdf`（15 页，150 分制）。
> 统计口径：试卷正文（题干、文章、选项）共切出 **2848 个有效英文词次**，另剔除人名地名等专名/噪声 **150 词次**；逐词与牌组 2219 个去重词头及其屈折形式（复数、时态、-ing、比较级、-ly、不规则变化）机器比对，全部结果经人工抽样复核。

## 一、结论速览

1. **牌组本身直接覆盖试卷 43.5% 的英文词次（53.3% 的不同词形）**。比例看似不高，是因为牌组刻意不收 the / and / of / make / year / student 这类你本来就会的基础词；把高中/学前应会词计入后，**现实覆盖率为 92.7% 词次、87.1% 不同词形**——这套牌与真题的词汇层次总体是匹配的。
2. 试卷中真正“没覆盖到”的生词为 **146 个不同词形、208 词次**，其中直接卡答案的只有 6 处：阅读第 2 题 greenery，完形第 22（goji）、29（positive）、30（equivalent）、36（essence）题，英译汉选择第 47 题（nestled/villas/exceptionally）。
3. **估分（满分 150）：保守约 90 分，中位约 109 分，乐观约 124 分。** 前提是语法、阅读技巧、改错训练和写作模板处于正常水平；词汇覆盖率不等于得分率，改错（20 分）和写作（20 分）主要不取决于认不认识词。
4. 牌组的主要短板是**缺一批四级/专升本高频词**（positive、equivalent、essence、essential、crucial、establish、generate、emphasize、recognize、pursue、engage 等，完整名单见第七节），且**不产出**：汉译英参考译文里 optimistic、essential、rural、residents、landscape 等词牌组没有，需要单独背拼写和用法。

### 2.4 编排特征（重要）

- 牌组是**词根词缀家族式**编排，不是字母顺序大纲：同一家族的词成串出现（如 band / bond / bend / bind / bound / boundary / bunch / bundle；pose / position / compose / oppose / expose / impose / propose / dispose），背一个词头等于带一串。
- 牌组**默认你已经掌握最基础词**：the、and、of、in、is、it、we、you 等功能词，以及 tree、student、make、time、year、world、train、learn、teach、restaurant 等初等词均无卡片（已在原始文件中逐条检索确认，不是解析遗漏）；但 good、have、all、school、life、say、work、go 等部分基础词又有收录，取舍并不完全一致。
- 因此评估这套牌的真实效果时，必须在牌组之外叠加“高中/学前基础词”层（本报告第四、六节均给出两种口径）。

### 6.3 估分模型与假设（务必阅读）

- 四选一题期望正确率 = 0.25 +（场景正确率 p − 0.25）×该题词汇就绪度；p 取 0.78 / 0.88 / 0.95。判断题随机基线 0.5，p 取 0.85 / 0.92 / 0.97。
- 答案词本身是生词的 6 道题（2、22、29、30、36、47）按猜对概率封顶 0.30–0.50；46、49、50 为 cannot...too、none but、独立主格等句型/习语题，与词汇量无关，封顶处理。
- 汉译英、改错、写作不是词汇题：表中分值为经验性场景估计（改错 8/12/15，写作 9/12/15，汉译英 5–14），假设你**经过常规语法与写作训练**。若语法薄弱或没有写作模板，实际分数会向保守档甚至更低移动；反之这三块训练充分，可向乐观档移动。
- 该卷为**回忆版**，题目文字可能与真题有出入；估分是概率期望，不是你的真实成绩保证。

## 十、方法与局限

1. 牌组用正则解析卡条（`**编号. 词头 词性**`），处理了不间断空格、音标粘连、多词短语、缩写卡与词根概念卡；解析结果经编号连续性断言（1–2329 无缺重）与人工抽样核对。
2. 试卷用 pdftotext -layout 抽取，按状态机切分为 11 个统计区段；token 化处理了缩写（I've / won't）、所有格、连字符复合词、序数噪声与选项标签。
3. 屈折匹配为纯规则引擎（无外网，WordNet 语料不可用），覆盖规则复数/时态/-ing/-er/-est/-ly、CVC 双写、y 变 i 及约 150 个不规则动词/名词/形容词，19 个自测样例全部通过；曾出现 busy→bus、every→ever 之类贪心假阳性，已全部剔除，词族推知仅保留人工白名单与同源屈折还原。
4. “高中基础词”层依据现行高中/高考词表人工核定（含数字、代词、方位、常见动词名词及本卷涉及的常见国籍词），完整名单见 8.3，可逐条审查。
5. 局限：回忆版试卷文本可能有误；机器匹配无法处理跨词性的远引申义；写作、改错、汉译英的分数依赖语法与输出训练，模型只给区间不给保证。
