# 03 · 通用模板：拿到式子就能画

> [!note] 本章回答的问题
> 书写逻辑到底是什么？"固定 x 扫 y"和求积分时"切片"的直觉为什么像、又为什么不是同一回事？
> 为什么 z 直接用原式？怎样从任意式子出发，一步步写出可运行代码？

---

## 一、书写逻辑：不是"照图描"，是"采样连线"

先纠正一个最常见的误解：

> [!danger] 误区
> "画三维图像 = 我先在脑子里想出图像长什么样，再照着描出来。"
> 这个想法**完全错误**。

**正确逻辑是**：

1. 拿到式子 $z=f(x,y)$；
2. 选定视角（三个投影向量）；
3. 用**截面法**在曲面上"切"出一族曲线；
4. 每条曲线用 `plot` 采样连线；
5. 两族曲线正交，织成曲面。

**图像是公式算出来的，你只是负责组织"采样-连线"这个过程。** 脑子里有没有图像，不影响画图。

---

## 二、"固定 x 扫 y"到底在做什么？和积分哪里像、哪里不同？

### 1. 你为什么会联想到积分

求积分（尤其是"切片法/元素法"）时，经典逻辑是：

> 把体积**切成薄片** → 研究其中一片 → 把无数片**累加**起来。

而画曲面时：

> 用平面 $x=\text{常数}$ 去**切曲面** → 得到一条交线 → 画很多条交线**并排**摆着。

两者都用了"**切片**"这个动作，所以你会觉得像。**你的直觉是对的，它们共享"切片"思想。**

### 2. 但本质完全不同

| 维度 | 积分切片法 | 画曲面截面法 |
|------|-----------|-------------|
| 切片后做什么 | 求面积/体积，**累加（积分）** | 只是把交线**画出来** |
| 涉及运算 | 求和、取极限、微积分 | 只代入函数算 z，**纯算术** |
| 目标 | 得到一个数值（面积/体积） | 得到一张图（曲面） |

> [!summary] 一句话区分
> 积分是"切片 + **累加**"，画图是"切片 + **描线**"。
> 画图**没有积分、没有求导**，只是把 $f(x,y)$ 当"高度计算器"用。

---

## 三、为什么"z 直接用原式"？

曲面的**定义**就是：

$$
z = f(x,y)
$$

也就是说：**只要给出一个 $(x,y)$，就有一个唯一的 $z$ 与之对应**，这个 $z$ 就是函数值。

所以当你固定 $x=-2.5$，让 $y$ 扫过时：

- 取一个 $y$（比如 $y=1$）；
- 把 $x=-2.5,\ y=1$ 一起代入 $f$；
- 算出 $z=f(-2.5, 1)$；
- 点 $(-2.5, 1, z)$ 就在曲面上。

把这条线上所有 $y$ 都这么算，连起来，就是曲面上的一条**真实交线**。

> [!tip] 为什么必须用原式？
> 因为你要让点**落在曲面上**。曲面上点的定义就是 $z=f(x,y)$。
> 用别的（比如导数、偏导）算出来的就不是曲面上的点，图就错了。

## 四、万能模板（背下这一页就够用）

```latex
\begin{document}
\begin{tikzpicture}[
  x={(-0.866cm,-0.5cm)},   % 视角：x轴投影（斜下方）
  y={(0.866cm,-0.5cm)},    % 视角：y轴投影（斜下方）
  z={(0cm,1cm)},           % 视角：z轴投影（竖直向上）
  >=stealth]               % 箭头样式

% ① 坐标轴（按函数范围调整数值）
\draw[->] (xmin,0,0) -- (xmax,0,0) node[right]{$x$};
\draw[->] (0,ymin,0) -- (0,ymax,0) node[right]{$y$};
\draw[->] (0,0,zmin) -- (0,0,zmax) node[above]{$z$};

% ② 族1：固定 x，扫 y
\foreach \xx in {x1, x2, ..., xN}{
  \draw[thin] plot[domain=ymin:ymax, samples=50, variable=\yy]
    (\xx, \yy, {f(\xx,\yy)});
}

% ③ 族2：固定 y，扫 x
\foreach \yy in {y1, y2, ..., yN}{
  \draw[thin] plot[domain=xmin:xmax, samples=50, variable=\xx]
    (\xx, \yy, {f(\xx,\yy)});
}

\end{tikzpicture}
\end{document}
```

> [!info] 模板使用说明
> 上面 `f(\xx,\yy)` 是**占位符**，代表你的函数式。
> 实际写代码时，把它**原样翻译成 TikZ 数学表达式**填进去（翻译规则见下一节）。

## 五、从数学式到 TikZ 表达式的翻译规则

拿到任意 $z=f(x,y)$，按下面规则逐项翻译：

| 数学          | TikZ                | 备注                   |          |     |
| ----------- | ------------------- | -------------------- | -------- | --- |
| $x^2,\ y^2$ | `\xx*\xx`、`\yy*\yy` | 平方用乘法，**不要用 `^`**    |          |     |
| $x^n$（一般幂）  | `pow(\xx, n)`       | `pow(底, 指数)` 安全      |          |     |
| $e^u$       | `exp(u)`            | `exp()` 是 $e$ 的幂     |          |     |
| $\ln u$     | `ln(u)`             | 自然对数                 |          |     |
| $\sin u$    | `sin(u r)`          | 角度转弧度：`(u r)`        |          |     |
| $\cos u$    | `cos(u r)`          | 同上                   |          |     |
| $\tan u$    | `tan(u r)`          | 同上                   |          |     |
| $\sqrt{u}$  | `sqrt(u)`           | 开方                   |          |     |
| $           | u                   | $                    | `abs(u)` | 绝对值 |
| 乘号          | `*`                 | 不能省略，`2x` 要写 `2*\xx` |          |     |
| 除号          | `/`                 | `\xx/2`              |          |     |
| $\pi$       | `pi`                | 常数                   |          |     |

### 举例

**例 1**：$z=\sin x\cos y$

```latex
{ sin(\xx r) * cos(\yy r) }
```

**例 2**：$z=\sqrt{x^2+y^2}$（圆锥）

```latex
{ sqrt(\xx*\xx + \yy*\yy) }
```

**例 3**：$z=\dfrac{\sin\sqrt{x^2+y^2}}{\sqrt{x^2+y^2}}$（墨西哥草帽）

```latex
{ sin(sqrt(\xx*\xx+\yy*\yy) r) / sqrt(\xx*\xx+\yy*\yy) }
```

## 六、完整实操：从式子到代码，五步走

以 $z=5(x^2+y^2)e^{-(x^2+y^2)}$ 为例，走一遍完整流程。

### 第 1 步：确定定义域

题目没给，就自己选一个**能看到主要形状的范围**。本例取 $x,y\in[-2.5, 2.5]$（因为函数在半径 1 处达峰，2.5 已经能看到衰减）。

### 第 2 步：写视角（照抄即可）

```latex
\begin{tikzpicture}[x={(-0.866cm,-0.5cm)},y={(0.866cm,-0.5cm)},z={(0cm,1cm)},>=stealth]
```

### 第 3 步：画坐标轴（范围对齐定义域）

```latex
\draw[->] (-3.2,0,0)--(3.4,0,0) node[right]{$x$};
\draw[->] (0,-3.2,0)--(0,3.4,0) node[right]{$y$};
\draw[->] (0,0,0)--(0,0,2.3) node[above]{$z$};
```

（z 轴上限 2.3 是因为函数最大值约 1.84，留点余量。）

### 第 4 步：翻译函数式

$$
5(x^2+y^2)e^{-(x^2+y^2)}
\quad\longrightarrow\quad{5*(\textbackslash xx*\textbackslash xx+\textbackslash yy*\textbackslash yy)*exp(-(\textbackslash xx*\textbackslash xx+\textbackslash yy*\textbackslash yy))}
$$

### 第 5 步：套进两族线模板

```latex
\foreach \xx in {-2.5,-2,...,2.5}{
  \draw[thin] plot[domain=-2.5:2.5,samples=50,variable=\yy]
    (\xx,\yy,{5*(\xx*\xx+\yy*\yy)*exp(-(\xx*\xx+\yy*\yy))});
}
\foreach \yy in {-2.5,-2,...,2.5}{
  \draw[thin] plot[domain=-2.5:2.5,samples=50,variable=\xx]
    (\xx,\yy,{5*(\xx*\xx+\yy*\yy)*exp(-(\xx*\xx+\yy*\yy))});
}
```

完成。

## 七、怎么调整"好不好看"？

| 想改什么     | 改哪里                               |
| -------- | --------------------------------- |
| 曲线太稀/太密  | 改 `\foreach` 的步长（`...,` 的第二项间距）   |
| 曲线太粗糙/太卡 | 改 `samples`（50 光滑，20 粗糙，100 更细但慢） |
| 显示范围     | 改 `domain` 和坐标轴数值                 |
| 线条颜色     | `\draw[thin, red]` 或 `blue!50` 等  |
| 视角       | 改开头三个投影向量                         |
| 整体大小     | 加 `scale=0.6` 到 tikzpicture 选项    |

---

## 八、本章小结

1. **书写逻辑**：拿到式子 → 定视角 → 截面法切片 → plot 采样连线 → 两族线成网。
2. **和积分的关系**：共享"切片"思想，但画图只描线不累加，**无微积分运算**。
3. **z 用原式**：因为曲面定义就是 $z=f(x,y)$，代入即得曲面上的点。
4. **万能模板**：两族 `\foreach` + `plot`，把函数式填进 `{...}` 即可。
