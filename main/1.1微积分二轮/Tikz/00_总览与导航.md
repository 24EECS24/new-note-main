# TikZ 三维函数绘图完全指南 · 总览

> [!summary] 这份笔记要解决什么问题
> 给你**任意一个二元函数** $z=f(x,y)$（比如 $z=5(x^2+y^2)e^{-(x^2+y^2)}$），
> 你就能**自己写出 TikZ 代码**，在 Obsidian 里画出它的三维曲面图。
> 不需要背任何"现成图像"，不需要手动画图——**图像是公式算出来的，不是描出来的**。

---

## 一、先建立最重要的认知

TikZ 画三维曲面，本质只做一件事：

> **采点 + 连线 + 循环**。

1. 在定义域里取**很多个**点 $(x,y)$；
2. 每个点代入公式算出 $z=f(x,y)$；
3. 把相邻点用短直线连起来，连成一条曲线；
4. 把很多条曲线**并排**画出来，就"织"成一张曲面。

你看到的曲面，其实是**几十条曲线编成的渔网**。所有点的位置都是公式算出来的，没有任何一个坐标是"照着图描"的。

## 三、三句话速记（核心套路）

1. **开头定视角**：`x={(-0.866cm,-0.5cm)}, y={(0.866cm,-0.5cm)}, z={(0cm,1cm)}` —— 这三行是"从斜上方看"的投影设定。
2. **画图靠两族线**：固定 $x$ 扫 $y$ 画一族，固定 $y$ 扫 $x$ 画另一族，两族线正交交叉成网格。
3. **z 永远直接用原式**：曲面的定义就是 $z=f(x,y)$，代入算高度，**和求导、积分都无关**（详见 03）。

## 四、配套可运行示例

以下是一份完整、已验证可直接编译的示例代码（画 $z=5(x^2+y^2)e^{-(x^2+y^2)}$，环形山/火山口形状）：

````tikz
\begin{document}
\begin{tikzpicture}[x={(-0.866cm,-0.5cm)},y={(0.866cm,-0.5cm)},z={(0cm,1cm)},>=stealth]
\draw[->] (-3.2,0,0)--(3.4,0,0) node[right]{$x$};
\draw[->] (0,-3.2,0)--(0,3.4,0) node[right]{$y$};
\draw[->] (0,0,0)--(0,0,2.3) node[above]{$z$};
% 固定 x，扫 y
\foreach \xx in {-2.5,-2,...,2.5}{
  \draw[thin] plot[domain=-2.5:2.5,samples=50,variable=\yy]
    (\xx,\yy,{5*(\xx*\xx+\yy*\yy)*exp(-(\xx*\xx+\yy*\yy))});
}
% 固定 y，扫 x
\foreach \yy in {-2.5,-2,...,2.5}{
  \draw[thin] plot[domain=-2.5:2.5,samples=50,variable=\xx]
    (\xx,\yy,{5*(\xx*\xx+\yy*\yy)*exp(-(\xx*\xx+\yy*\yy))});
}
\end{tikzpicture}
\end{document}
````

> [!warning] 注意两个致命细节（详见 04）
> - 平方写成 `\xx*\xx`，**不要**写 `\xx^2`（负数会算错，图像负半轴畸变）。
> - 循环变量 `\xx` 和 plot 自变量 `\yy` 不能重名，用 `variable=` 明确区分。
