
> [!summary] 这篇手册解决什么问题
> 给你**任意一种三维图像**，你能立刻判断它属于哪一类、该用哪个模板、需要改哪几处、为什么要那样改。
> 看完这篇 + 前面 00~04，就能实现"**任何三维图像都能画**"。
>
> 本文把三维图像分成 **4 类**，每类一个模板，配"改动清单表"，改完清单就能画出新图。

## 0. 先看决策树：拿到图，第一步判断类型

```
拿到一个三维图像/式子
        │
        ├─ 能写成 z = f(x,y) ？  ──────是──→ 【类型A】显函数曲面（占90%）
        │
        ├─ 给的是参数方程
        │   x=x(u,v), y=y(u,v), z=z(u,v) ？ ──是──→ 【类型B】参数曲面（球面/环面）
        │
        ├─ 是"闭合"的（球、椭球、甜甜圈）？ ──是──→ 【类型C】闭合曲面（要处理遮挡）
        │
        └─ 给的是 F(x,y,z)=0 隐式方程？ ──是──→ 【类型D】隐函数（先显化/参数化）
```

四类速查：

| 类型 | 典型例子 | 用什么模板 | 最大难点 |
|------|---------|-----------|---------|
| A 显函数 | $z=x^2+y^2$、$z=\sin x\cos y$ | 两族截面线（前面 00~04 已学） | 无，改式子即可 |
| B 参数曲面 | 球面、环面、螺旋面 | 参数方程两族线 | 参数公式要写对 |
| C 闭合曲面 | 球、椭球、甜甜圈 | 参数线框 + 分层遮挡 | 前后线穿透 |
| D 隐函数 | $x^2+y^2+z^2=1$ | 显化/参数化后再用 A 或 B | 解出 z 或参数化 |

## 1. 类型A：显函数曲面 z=f(x,y)（最常用，覆盖 90%）

### 1.1 模板（照抄，只改标注处）

```latex
\begin{tikzpicture}[x={(-0.866cm,-0.5cm)},y={(0.866cm,-0.5cm)},z={(0cm,1cm)},>=stealth]
% ①坐标轴：上限按"定义域+值域"改
\draw[->] (-3.2,0,0)--(3.4,0,0) node[right]{$x$};
\draw[->] (0,-3.2,0)--(0,3.4,0) node[right]{$y$};
\draw[->] (0,0,0)--(0,0,2.3) node[above]{$z$};
% ②族1：固定 x，扫 y
\foreach \xx in {-2.5,-2,...,2.5}{           % ③步长按起伏改
  \draw[thin] plot[domain=-2.5:2.5,samples=50,variable=\yy]  % ④domain按定义域改
    (\xx,\yy,{5*(\xx*\xx+\yy*\yy)*exp(-(\xx*\xx+\yy*\yy))});  % ⑤函数式(唯一必改)
}
% ⑥族2：固定 y，扫 x（和族1完全对称）
\foreach \yy in {-2.5,-2,...,2.5}{
  \draw[thin] plot[domain=-2.5:2.5,samples=50,variable=\xx]
    (\xx,\yy,{5*(\xx*\xx+\yy*\yy)*exp(-(\xx*\xx+\yy*\yy))});
}
\end{tikzpicture}
```

````tikz
}

````

### 1.2 改动清单（四件套 + 一个唯一必改项）

| 序号 | 改什么 | 在哪 | 怎么定 | 为什么 |
|------|--------|------|--------|--------|
| ⑤ | **函数式** | 两个 `{...}` | 按翻译规则写（平方用 `\xx*\xx`，$e$ 用 `exp()`） | 唯一决定"画什么" |
| ④ | `domain` | 两处 | = 自变量取值范围 | 不看全/看到没意义的区域 |
| ① | 坐标轴上限 | 三行 `\draw` | ≥ 定义域和值域 | 轴太短，曲面被"切"掉 |
| ③ | `\foreach` 步长 | 两个列表 | 起伏越快步长越小 | 步长太大，网格稀、曲面走样 |

> [!tip] 四件套是**绑定的**，一起改。只改函数式不改 domain，最常见的后果就是曲面跑出图框或关键形状没显示。

### 1.3 为什么 z 直接用原式（再强调一次）

曲面定义就是 $z=f(x,y)$，所以固定 $x$ 后，每个 $y$ 对应的 $z$ 就是代入算出的函数值。**无求导、无积分**，纯算术代入。详见 [[03_通用模板_拿到式子就能画]]。

## 2. 类型B：参数曲面（球面、环面、螺旋面）

### 2.1 什么是参数方程？（直觉）

显函数是"给 $(x,y)$ 算 $z$"，但球面一个 $(x,y)$ 对应**两个** $z$（上半球、下半球），写不成单值函数。

参数方程换思路：用**两个角度 $(u,v)$** 来描述点，像地球的**经度 + 纬度**定位：

- 球面：经度 $\theta$ + 纬度 $\varphi$ 确定一个点；
- 环面：大圆角度 $u$ + 小圆（管截面）角度 $v$。

每个点由 $(u,v)$ 唯一确定，$x,y,z$ 都是 $(u,v)$ 的函数。

### 2.2 模板（参数版两族线）

```latex
\begin{tikzpicture}[x={(-0.866cm,-0.5cm)},y={(0.866cm,-0.5cm)},z={(0cm,1cm)},>=stealth]
\draw[->] ...;   % 坐标轴按需要画
% 族1：固定 v，扫 u（第一族参数线）
\foreach \v in {v的取值列表}{
  \draw plot[domain=u范围, samples=60, variable=\u]
    ({x(\u,\v)}, {y(\u,\v)}, {z(\u,\v)});
}
% 族2：固定 u，扫 v（第二族参数线）
\foreach \u in {u的取值列表}{
  \draw plot[domain=v范围, samples=60, variable=\v]
    ({x(\u,\v)}, {y(\u,\v)}, {z(\u,\v)});
}
\end{tikzpicture}
```

> [!info] 和类型A的区别只有一点
> 类型A的坐标是 `(\xx, \yy, {z式})`，前两项就是 `\xx`、`\yy` 本身。
> 类型B的坐标三项 `({x式}, {y式}, {z式})` **全部是参数的函数**，都要写。

### 2.3 改动清单

| 改什么 | 怎么定 |
|--------|--------|
| 三个参数式 `x(u,v), y(u,v), z(u,v)` | 按几何定义写（见下方实例） |
| 两个参数的取值范围 | 球面：$\theta\in[0,360°]$、$\varphi\in[0,180°]$ |
| `\foreach` 步长 | 决定经线/纬线数量 |

### 2.4 实例1：球面（经纬线，半径 1.5）

参数方程（$\varphi$=极角，$\theta$=方位角，单位度）：
$$
x=R\sin\varphi\cos\theta,\quad y=R\sin\varphi\sin\theta,\quad z=R\cos\varphi
$$
```latex
\begin{tikzpicture}[x={(-0.866cm,-0.5cm)},y={(0.866cm,-0.5cm)},z={(0cm,1cm)},>=stealth]
\draw[->] ...;   % 坐标轴按需要画
% 族1：固定 v，扫 u（第一族参数线）
\foreach \v in {v的取值列表}{
  \draw plot[domain=u范围, samples=60, variable=\u]
    ({x(\u,\v)}, {y(\u,\v)}, {z(\u,\v)});
}
% 族2：固定 u，扫 v（第二族参数线）
\foreach \u in {u的取值列表}{
  \draw plot[domain=v范围, samples=60, variable=\v]
    ({x(\u,\v)}, {y(\u,\v)}, {z(\u,\v)});
}
\end{tikzpicture}
```

````tikz
\begin{document}
\begin{tikzpicture}[x={(-0.866cm,-0.5cm)},y={(0.866cm,-0.5cm)},z={(0cm,1cm)},>=stealth]
\draw[->] (-1.8,0,0)--(1.8,0,0) node[right]{$x$};
\draw[->] (0,-1.8,0)--(0,1.8,0) node[right]{$y$};
\draw[->] (0,0,-1.8)--(0,0,1.8) node[above]{$z$};
% 纬线：固定极角 φ，方位角 θ 扫 0~360
\foreach \ph in {30,60,90,120,150}{
  \draw[thin] plot[domain=0:360,samples=60,variable=\th]
    ({1.5*sin(\ph)*cos(\th)},{1.5*sin(\ph)*sin(\th)},{1.5*cos(\ph)});
}
% 经线：固定方位角 θ，极角 φ 扫 0~180
\foreach \th in {0,30,...,330}{
  \draw[thin] plot[domain=0:180,samples=40,variable=\ph]
    ({1.5*sin(\ph)*cos(\th)},{1.5*sin(\ph)*sin(\th)},{1.5*cos(\ph)});
}
\end{tikzpicture}
\end{document}
````

> [!tip] 注意角度
> 这里 $\varphi,\theta$ 都是"度"，TikZ 的 `sin/cos` 默认按度算，所以**直接写 `sin(\ph)`、`cos(\th)`，不要加 `r`**。
> （类型A里写 `sin(\xx r)` 是因为把 $x$ 当弧度；这里角度本来就是度，不加 `r`。）

### 2.5 实例2：环面（甜甜圈，大半径 2，管半径 0.7）

参数方程（$u$=环向大圆角，$v$=管截面角）：
$$
x=(R+r\cos v)\cos u,\quad y=(R+r\cos v)\sin u,\quad z=r\sin v
$$

````tikz
\begin{document}
\begin{tikzpicture}[x={(-0.866cm,-0.5cm)},y={(0.866cm,-0.5cm)},z={(0cm,1cm)},>=stealth]
\draw[->] (-3,0,0)--(3,0,0) node[right]{$x$};
\draw[->] (0,-3,0)--(0,3,0) node[right]{$y$};
\draw[->] (0,0,-1.2)--(0,0,1.2) node[above]{$z$};
% 环向大圆：固定管角 v，环向角 u 扫
\foreach \v in {0,30,...,330}{
  \draw[thin] plot[domain=0:360,samples=60,variable=\u]
    ({(2+0.7*cos(\v))*cos(\u)},{(2+0.7*cos(\v))*sin(\u)},{0.7*sin(\v)});
}
% 管截面小圆：固定环向角 u，管角 v 扫
\foreach \u in {0,30,...,330}{
  \draw[thin] plot[domain=0:360,samples=60,variable=\v]
    ({(2+0.7*cos(\v))*cos(\u)},{(2+0.7*cos(\v))*sin(\u)},{0.7*sin(\v)});
}
\end{tikzpicture}
\end{document}
````

## 3. 类型C：闭合曲面的遮挡（消隐）问题

### 3.1 为什么闭合曲面难画？

纯 TikZ 画的是**线框**，没有自动消隐——它不知道哪条线该被前面挡住。球面、环面这种闭合曲面，**后面的线会"透"过前面**，看起来一团乱。

### 3.2 解法1：分层画（后层浅色 → 前层实色，最实用）

核心思想：**先画"在后面"的线（浅灰），再画"在前面"的线（深色实线）覆盖上去**，用颜色深浅模拟前后遮挡。

在标准视角（$y$ 轴朝右下方=前方）下，判断前后很简单：

- 点在前半球 $\Leftrightarrow$ $y\ge 0$ $\Leftrightarrow$ 方位角 $\theta\in[0°,180°]$
- 点在后半球 $\Leftrightarrow$ $y<0$ $\Leftrightarrow$ $\theta\in[180°,360°]$

### 3.3 实例：分层球面（前半球实线、后半球浅灰）

````tikz
\begin{document}
\begin{tikzpicture}[x={(-0.866cm,-0.5cm)},y={(0.866cm,-0.5cm)},z={(0cm,1cm)},>=stealth]
\draw[->] (-1.8,0,0)--(1.8,0,0) node[right]{$x$};
\draw[->] (0,-1.8,0)--(0,1.8,0) node[right]{$y$};
\draw[->] (0,0,-1.8)--(0,0,1.8) node[above]{$z$};

% ===== 第1层：后半球（浅灰），先画 =====
% 后半球纬线（方位角 180~360）
\foreach \ph in {30,60,90,120,150}{
  \draw[gray!60,thin] plot[domain=180:360,samples=30,variable=\th]
    ({1.5*sin(\ph)*cos(\th)},{1.5*sin(\ph)*sin(\th)},{1.5*cos(\ph)});
}
% 后半球经线（θ 取 180~330）
\foreach \th in {180,210,...,330}{
  \draw[gray!60,thin] plot[domain=0:180,samples=30,variable=\ph]
    ({1.5*sin(\ph)*cos(\th)},{1.5*sin(\ph)*sin(\th)},{1.5*cos(\ph)});
}

% ===== 第2层：前半球（实线），后画，盖住浅灰 =====
\foreach \ph in {30,60,90,120,150}{
  \draw[thin] plot[domain=0:180,samples=30,variable=\th]
    ({1.5*sin(\ph)*cos(\th)},{1.5*sin(\ph)*sin(\th)},{1.5*cos(\ph)});
}
\foreach \th in {0,30,...,150}{
  \draw[thin] plot[domain=0:180,samples=30,variable=\ph]
    ({1.5*sin(\ph)*cos(\th)},{1.5*sin(\ph)*sin(\th)},{1.5*cos(\ph)});
}
\end{tikzpicture}
\end{document}
````

> [!warning] 诚实说明
> 这是**近似遮挡**（靠颜色深浅），不是真正的自动消隐。线框图的线条本身仍会交叉，
> 但"前实后浅"已经能让球面结构清晰可读，足够教学和笔记用。
> 想要**完美消隐 + 自动上色**，请看第 5 节的 pgfplots 方案。

## 4. 类型D：隐函数 F(x,y,z)=0

### 4.1 能显化：解出 z，分片画

方程 $x^2+y^2+z^2=1$ 解出：

$$
z=\pm\sqrt{1-x^2-y^2}
$$

分**上下两片**，各用一次类型A模板。

````tikz
\begin{document}
\begin{tikzpicture}[x={(-0.866cm,-0.5cm)},y={(0.866cm,-0.5cm)},z={(0cm,1cm)},>=stealth]
\draw[->] (-1.3,0,0)--(1.3,0,0) node[right]{$x$};
\draw[->] (0,-1.3,0)--(0,1.3,0) node[right]{$y$};
\draw[->] (0,0,-1.3)--(0,0,1.3) node[above]{$z$};
% 上半球：z = +sqrt(1-x²-y²)
\foreach \xx in {-1,-0.8,...,1}{
  \draw[thin] plot[domain=-1:1,samples=40,variable=\yy]
    (\xx,\yy,{sqrt(max(0,1-\xx*\xx-\yy*\yy))});
}
\foreach \yy in {-1,-0.8,...,1}{
  \draw[thin] plot[domain=-1:1,samples=40,variable=\xx]
    (\xx,\yy,{sqrt(max(0,1-\xx*\xx-\yy*\yy))});
}
% 下半球：z = -sqrt(1-x²-y²)
\foreach \xx in {-1,-0.8,...,1}{
  \draw[thin] plot[domain=-1:1,samples=40,variable=\yy]
    (\xx,\yy,{-sqrt(max(0,1-\xx*\xx-\yy*\yy))});
}
\foreach \yy in {-1,-0.8,...,1}{
  \draw[thin] plot[domain=-1:1,samples=40,variable=\xx]
    (\xx,\yy,{-sqrt(max(0,1-\xx*\xx-\yy*\yy))});
}
\end{tikzpicture}
\end{document}
````

> [!tip] `max(0,...)` 是保命技巧
> 当 $x^2+y^2>1$（圆外）时，$1-x^2-y^2$ 是负数，`sqrt(负数)` 会报错。
> 用 `sqrt(max(0,1-\xx*\xx-\yy*\yy))` 把负值压成 0，圆外就"贴地"，不报错。

### 4.2 不能显化（或显化很丑）：改参数化

很多隐函数解不出干净的 $z$，这时回到**类型B**，把曲面参数化（球面→经纬度，环面→两个角度）。**球面这类，参数化画法（2.4 节）比显化分片更干净**。

## 5. pgfplots 进阶：自动上色 + 自动消隐的"正道"

### 5.1 重要前提（先看清楚，别踩坑）

> [!danger] TikZJax 不支持 pgfplots
> Obsidian 的 TikZJax 插件只内置了 **TikZ 核心**，**不含 pgfplots** 这个大库。
> 下面的 pgfplots 代码**在 Obsidian 里渲染不出来**，必须用**本地 LaTeX（TeXLive/MiKTeX）或 Overleaf** 编译。

### 5.2 典型代码（本地编译用，自动上色+消隐）

```latex
\documentclass{standalone}
\usepackage{pgfplots}
\pgfplotsset{compat=1.18}
\begin{document}
\begin{tikzpicture}
\begin{axis}[
  view={60}{30},          % 视角：绕x轴转60°，绕z轴转30°
  xlabel=$x$, ylabel=$y$, zlabel=$z$,
  colormap/viridis]       % 配色
\addplot3[
  surf,                   % 画实心曲面
  domain=-2:2,            % x 范围
  domain y=-2:2,          % y 范围
  samples=40]             % 采样密度
  {5*(x^2+y^2)*exp(-(x^2+y^2))};   % 函数式（pgfplots 里 ^ 是安全的）
\end{axis}
\end{tikzpicture}
\end{document}
```

### 5.3 什么时候用 pgfplots，什么时候用纯 TikZ？

| 需求 | 用哪个 |
|------|--------|
| Obsidian 笔记里快速画 $z=f(x,y)$ | **纯 TikZ**（类型A模板） |
| Obsidian 里画球面/环面线框 | **纯 TikZ 参数方程**（类型B/C） |
| 要**自动上色、完美消隐**的实心曲面 | **pgfplots**（本地编译/Overleaf） |
| 要等高线、色标、坐标平面网格 | **pgfplots** |

> [!summary] 一句话
> **Obsidian 里就用纯 TikZ（本笔记模板 A/B/C/D）**；
> **要出版级、上色、消隐的图，用 pgfplots 本地编译**。两者配合，天下三维图都能画。

## 6. 参数调优速查总表（一页纸）

| 想调整 | 改哪个参数 | 怎么改 | 为什么 |
|--------|-----------|--------|--------|
| 曲面形状 | 函数式 `{...}` | 翻译成 TikZ 表达式 | 决定 z 值 |
| 显示范围 | `domain` | = 定义域 | 看全/看对区域 |
| 轴长度 | 三行 `\draw[->]` | ≥ 定义域和值域 | 轴太短切图 |
| 网格密度 | `\foreach` 步长 | 起伏快→步长小 | 密网才贴合曲面 |
| 曲线光滑度 | `samples` | 50 光滑、100 更细 | 采样点越多越平滑 |
| 线条颜色 | `\draw[thin, red]` | 换颜色名/`gray!60` | 区分前后层 |
| 视角 | 开头 `x=/y=/z=` | 改三个屏幕向量 | 决定观察角度 |
| 整体大小 | `scale=0.6` | 加到 tikzpicture 选项 | 缩放不改变坐标 |
| 遮挡（闭合曲面） | 分层+颜色 | 后层 `gray!60` 先画、前层实线后画 | 近似消隐 |

## 7. 总结：四类模板 = 一个万能工具箱

| 图像类型 | 判断方法 | 模板 | 必改项 |
|---------|---------|------|--------|
| A 显函数 | 能写 $z=f(x,y)$ | 两族截面线 | 函数式 + domain + 轴 + 步长 |
| B 参数曲面 | 给参数方程 | 参数两族线 | 三个参数式 + 参数范围 |
| C 闭合曲面 | 球/椭球/环面 | 参数线框 + 分层遮挡 | 参数式 + 前后分层颜色 |
| D 隐函数 | 给 $F(x,y,z)=0$ | 显化分片 / 参数化 | 解出 $z$ 或参数化 |
| 出版级 | 要上色消隐 | pgfplots（本地编译） | `view` + `surf` + `samples` |

> [!tip] 行动指南
> 1. 先判断类型（决策树 0 节）；
> 2. 复制对应模板；
