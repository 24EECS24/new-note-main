# 02 · 逐字符拆解：每个符号什么意思

> [!note] 本章回答的问题
> `>=stealth` 是什么？`\xx` 为什么是两个 x？`\foreach`、`plot`、`domain`、`samples`、`variable` 都是干什么的？
> 本章把上一章的完整示例代码**逐字符**拆开讲。

---

## 一、`>=stealth` 是什么意思？

完整写法是 `>=stealth`，它出现在 `tikzpicture` 的选项列表里：

```latex
\begin{tikzpicture}[..., >=stealth]
```

### 拆解

- `>` 是**箭头尖**的代称。TikZ 里 `\draw[->]` 画带箭头的线，这个箭头长什么样，由 `>` 的样式决定。
- `=` 是**赋值**，把 `>` 这个箭头样式设定为后面那个值。
- `stealth` 是**一种箭头样式名**（像隐形战斗机的尖锐箭头）。

所以 `>=stealth` 读作：**"把 `>` 这种箭头设定为 stealth 样式"**。

> [!tip] 为什么前面写 `->`？
> `\draw[->]` 里的 `-` 是"线"，`>` 是"箭头"，连起来 `->` = "线段 + 末端箭头"。
> 而 `>=stealth` 是全局设置这个箭头的**造型**（尖锐款）。
> 你可以把 `stealth` 换成 `latex`、`stealth'`、`to` 等，箭头形状会变。

## 二、`\xx` 为什么是两个 x？为什么不用 `\x`？

### 1. 反斜杠 `\` 是什么

在 LaTeX 里，`\xx` 表示一个**命令/宏/变量**。`\x`、`\y`、`\xx`、`\yy`、`\ra`、`\an` 都是"变量名"。

> 关键：**变量名是一个完整字符串**，`\xx` 不是"`\x` 再乘 `x`"，它就是名字叫 `xx` 的变量。

### 2. 为什么这里用 `\xx` 而不是 `\x`？

因为**要区分两个不同的变量，避免重名冲突**：

- 循环变量：`\foreach \xx in {...}` —— 这个 `\xx` 是"外层循环里固定下来的 x 值"；
- plot 自变量：`plot[..., variable=\yy]` —— 这个 `\yy` 是"曲线内部不断扫动的 y 值"。

用 `\xx`、`\yy` 这种双字母，是为了和单字母 `\x`、`\y` 区分开，**名字更醒目、更不容易混淆**。其实你完全可以这样写：

```latex
\foreach \a in {-2.5,-2,...,2.5}{
  \draw plot[domain=-2.5:2.5,samples=50,variable=\b]
    (\a,\b,{5*(\a*\a+\b*\b)*exp(-(\a*\a+\b*\b))});
}
```

效果一模一样。所以 **`\xx` 只是命名习惯，不是语法要求**。作者用 `xx` 是想暗示"这是 x 的循环值"。

> [!warning] 但绝对不能重名！
> 如果循环变量叫 `\x`，plot 自变量也叫 `\x`，两者会互相覆盖、坐标错乱（详见 04）。

## 三、`\foreach` 循环

```latex
\foreach \xx in {-2.5,-2,...,2.5}{ ... }
```

### 逐词拆解

| 片段 | 含义 |
|------|------|
| `\foreach` | 循环命令：把后面的事情重复做很多次 |
| `\xx` | 循环变量名 |
| `in {...}` | 循环变量依次取这些值 |
| `{-2.5,-2,...,2.5}` | 取值列表 |

### 列表的写法规则

`{-2.5, -2, ..., 2.5}` 里：
- 第一项是 `-2.5`（起点）；
- 第二项是 `-2`（第二个值）；
- TikZ 自动算出**公差** $= -2 - (-2.5) = 0.5$；
- 然后 `-2.5, -2, -1.5, -1, ..., 2.5` 一路加 0.5，直到 2.5。

所以这个循环会执行 **11 次**（从 -2.5 到 2.5，步长 0.5）。

> [!tip] 步长自己定
> 想更密：`{-2.5,-2.25,...,2.5}`（步长 0.25）。
> 想更疏：`{-2.5,-1.5,...,2.5}`（步长 1）。
> 也可以显式列出每个值：`{-2.5,-1.5,0,1,2.5}`。

## 四、`plot` 画函数曲线

```latex
\draw[thin] plot[domain=-2.5:2.5, samples=50, variable=\yy]
  (\xx, \yy, {公式});
```

### 逐词拆解

| 片段 | 含义 |
|------|------|
| `\draw` | 画图命令 |
| `[thin]` | 线条样式：细线（还可 `thick`、`dashed`、`red` 等） |
| `plot` | 画"函数图像"专用命令 |
| `domain=-2.5:2.5` | 自变量取值范围：从 -2.5 到 2.5 |
| `samples=50` | 采样点数量：在范围内取 50 个点 |
| `variable=\yy` | 把 plot 的自变量命名为 `\yy` |
| `(\xx, \yy, {公式})` | 每个采样点的三维坐标 |

### `plot` 的工作流程（重要！）

`plot` 内部是这样的一个机器：

```
1. 把 domain [-2.5, 2.5] 均分成 samples-1 段 → 得到 50 个点
   -2.5, -2.4, -2.3, ..., 2.5
2. 对每个点，把它代进坐标表达式的"自变量位置"
3. 把算出来的 50 个三维点连成折线
```

> [!summary] 核心记忆
> `plot` = **采样器 + 连线器**。点足够密（samples 大），折线看起来就是光滑曲线。

## 五、坐标 `(\xx, \yy, {公式})` 里三项各是什么？

这是整段代码最关键的一行：

```latex
(\xx, \yy, {5*(\xx*\xx+\yy*\yy)*exp(-(\xx*\xx+\yy*\yy))})
```

它对应三维坐标 $(x, y, z)$：

| 位置 | 代码 | 扮演角色 |
|------|------|---------|
| 第一项 | `\xx` | 这条曲线里是**固定的 x**（循环给的常数，比如 -2.5） |
| 第二项 | `\yy` | **自变量**，plot 让它从 -2.5 扫到 2.5 |
| 第三项 | `{公式}` | **高度 z**，把 x、y 代入函数算出来 |

> [!danger] 花括号 `{...}` 为什么必要？
> 第三项公式里有括号、有逗号、有乘号，TikZ 需要花括号把它**包成一个整体**，否则解析器会把公式里的 `(` `)` 误当成坐标分隔符。
> 记住：**坐标里的复杂数学表达式，一律用 `{...}` 包起来**。

## 六、公式 `5*(\xx*\xx+\yy*\yy)*exp(-(\xx*\xx+\yy*\yy))` 对应什么？

它就是把数学式 $z=5(x^2+y^2)e^{-(x^2+y^2)}$ 翻译成 TikZ 能算的写法。

对照表：

| 数学写法 | TikZ 写法 | 说明 |
|---------|----------|------|
| $x^2$ | `\xx*\xx` | 平方用乘法（不用 `^`，原因见下） |
| $x^2+y^2$ | `\xx*\xx+\yy*\yy` | 加法 |
| $5(x^2+y^2)$ | `5*(\xx*\xx+\yy*\yy)` | 系数相乘，`*` 不能省 |
| $e^{-(x^2+y^2)}$ | `exp(-(\xx*\xx+\yy*\yy))` | `exp()` 就是 $e$ 的幂 |

> [!warning] 为什么不写 `\xx^2`？
> TikZ 的数学引擎里，`-1^2` 会被算成 $-(1^2)=-1$，而不是 $(-1)^2=1$。
> 当 `\xx=-1` 时，`\xx^2` 展开成 `-1^2 = -1`，就**错了**（负半轴图像畸变）。
> 所以平方一律写 `\xx*\xx`，最安全。详见 04。

## 七、两族线为什么要对称地各写一遍？

看完整代码有两个 `\foreach`：

```latex
% 第一个循环：固定 \xx，扫 \yy（得到"沿 y 方向的线"）
\foreach \xx in {-2.5,-2,...,2.5}{
  \draw plot[domain=-2.5:2.5,samples=50,variable=\yy]
    (\xx,\yy,{公式});
}

% 第二个循环：固定 \yy，扫 \xx（得到"沿 x 方向的线"）
\foreach \yy in {-2.5,-2,...,2.5}{
  \draw plot[domain=-2.5:2.5,samples=50,variable=\xx]
    (\xx,\yy,{公式});
}
```

- **第一个循环**：每轮固定一个 `\xx`，让 `\yy` 从头扫到尾 → 画出的是一条**沿 y 方向延伸**的截面线；循环 11 次得到 11 条平行线。
- **第二个循环**：每轮固定一个 `\yy`，让 `\xx` 扫 → 画出**沿 x 方向**的 11 条线。

两族线**互相垂直交叉**，就编成一张网格，罩在曲面上，立体感就出来了。

> [!tip] 单族线 vs 两族线
> 只有第一族线：像一排"晾衣绳"，看不出面。
> 两族线正交：像"渔网"，能看出曲面起伏。
> 所以画曲面**必须两族线都画**。

## 八、小结速查表

| 符号 | 一句话解释 |
|------|-----------|
| `>=stealth` | 把箭头 `>` 设为 stealth（尖锐）样式 |
| `\xx`、`\yy` | 自定义变量名，双字母只为醒目、与 `\x` 区分，不是语法要求 |
| `\foreach \xx in {...}` | 循环，`\xx` 依次取列表里的值 |
| `plot` | 画函数曲线：采点+连线 |
| `domain=a:b` | 自变量范围 |
| `samples=N` | 取 N 个采样点，越大越光滑 |
| `variable=\yy` | 指定 plot 的自变量名字 |
| `{公式}` | 花括号包住坐标里的数学表达式 |
| `\xx*\xx` | 平方，避免 `^` 的负数坑 |
