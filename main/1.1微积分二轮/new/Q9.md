### 版面分析
1.  **整体布局**：笔记为左右分栏结构，左侧是二重积分对称性知识点，右侧是例题（例143）与解答，阅读顺序为先左后右、先知识点后例题。
2.  **左侧知识点区**：
    - 模块1：**D关于原点对称**，配2个3D曲面示意图（分别对应原点对称下的偶函数、奇函数），配套积分性质：
      - 若$f(-x,-y)=f(x,y)$（偶）：$\iint_D f\mathrm{d}\sigma = 2\iint_{D_1} f\mathrm{d}\sigma$（$D_1$为对称半区域）
      - 若$f(-x,-y)=-f(x,y)$（奇）：$\iint_D f\mathrm{d}\sigma = 0$
    - 模块2：**D关于$y=x$对称**，配1个第一卦限3D曲面示意图、1个2D点对称示意图，配套积分性质：
      - 若$f(y,x)=f(x,y)$（对称）：$\iint_D f\mathrm{d}\sigma = 2\iint_{D_1} f\mathrm{d}\sigma$（$D_1$为对称半区域）
      - 若$f(y,x)=-f(x,y)$（反对称）：$\iint_D f\mathrm{d}\sigma = 0$
3.  **右侧例题区**：
    - 题目：例143，比较三个二重积分$J_1,J_2,J_3$的大小，给出三个积分区域$D_1,D_2,D_3$；
    - 解答：利用被积函数$\sqrt[3]{x-y}$关于$y=x$的反对称性，结合$D_1$的对称性得$J_1=0$，配1个$D_1$区域的2D示意图。

    \draw[->] (0,0,0) -- (0,0,1.2) node[above,font=\small] {$z$};
    \draw[->] (0,0,0) -- (0,0,-1.2);
    \foreach \y in {-1,-0.75,...,1} {
        \draw[gridgreen,smooth,samples=10,domain=-1:1]
            plot (\x, \y, {\x*\y});
    }
    \foreach \x in {-1,-0.75,...,1} {
        \draw[gridgreen,smooth,samples=10,variable=\y,domain=-1:1]
            plot (\x, \y, {\x*\y});
    }

\end{document}

### 补充图像（例题区域对称示意图）
为了更清晰展示$D_2,D_3$关于$y=x$的对称性，补充绘制三个积分区域的关系图：
```tikz
\begin{document}
\definecolor{fillblue}{rgb}{0.2,0.4,0.8}
\definecolor{fillred}{rgb}{0.8,0.2,0.2}
\begin{tikzpicture}[x=1cm,y=1cm,scale=2]
    \draw[->] (-0.2,0) -- (1.3,0) node[right,font=\small] {$x$};
    \draw[->] (0,-0.2) -- (0,1.3) node[above,font=\small] {$y$};
    \node[below left,font=\small] at (0,0) {$O$};
    \draw (1,0) node[below,font=\small] {$1$};
    \draw (0,1) node[left,font=\small] {$1$};
    \draw[thick,gray] (0,0) -- (1.1,1.1) node[above right,font=\small] {$y=x$};
    % D2: 0≤y≤√x
    \fill[fillblue,opacity=0.3,smooth,samples=100,domain=0:1]
        plot(\x,{sqrt(\x)}) -- (1,0) -- cycle;
    \draw[thick,fillblue,smooth,samples=100,domain=0:1] plot(\x,{sqrt(\x)}) node[above right,font=\small] {$y=\sqrt{x}$};
    % D3: x²≤y≤1
    \fill[fillred,opacity=0.3,smooth,samples=100,domain=0:1]
        plot(\x,{\x*\x}) -- (0,1) -- cycle;
    \draw[thick,fillred,smooth,samples=100,domain=0:1] plot(\x,{\x*\x}) node[below right,font=\small] {$y=x^2$};
    \node[fillblue,font=\small] at (0.6,0.3) {$D_2$};
    \node[fillred,font=\small] at (0.3,0.6) {$D_3$};
\end{tikzpicture}
\end{document}
```
示意图说明：蓝色为$D_2$，红色为$D_3$，二者关于$y=x$对称；中间交集区域关于$y=x$对称（积分抵消为0），$D_2$剩余部分被积函数为正，$D_3$剩余部分被积函数为负，最终大小关系为$J_3<J_1=0<J_2$。
