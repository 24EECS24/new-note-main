### 版面分析
该页为偏导数入门的手写板书，无严格左右分栏，阅读顺序遵循从上到下、从左到右的逻辑：
1.  **头部区域**：顶部为标题「四、偏导数」，附带偏导符号$\partial$的读法说明；
2.  **对比（Compare）模块**：
    - 左上：一元函数的导数知识点，配1个2D平面示意图（$xOy$坐标系下，曲线在$x_0$处的切线），文字说明一元函数仅存在$x$轴方向的变化率；
    - 左下：二元函数偏导数的文字解释，说明二元函数有无穷多个方向的变化率，偏导数是「部分方向上的导数」，本质与一元函数导数一致，仅需指定方向；
3.  **右侧区域**：
    - 右上：二元函数对$x$偏导数的3D几何示意图（空间直角坐标系、曲面$z=f(x,y)$、平行于$xOz$的平面$y=y_0$、截线、截线上点$(x_0,y_0)$处的切线，标注$\Delta x$、投影点、切线倾角$\alpha$）；
    - 右中：几何意义文字说明（用平行于$x$轴的平面截曲面，得到$x$方向的变化率）；
    - 右下：偏导数的极限定义式，以及各类偏导数记号（$f'_x(x_0,y_0)$、$\frac{\partial f}{\partial x}$、$\frac{\partial z}{\partial x}$等）。

### 笔记原图的TikZJax实现
#### 1. 一元函数在$x_0$处的导数（切线示意图）
```tikz
\begin{document}
\begin{tikzpicture}[x=1cm,y=1cm,scale=1.2]
    % 绘制坐标轴
    \draw[->] (-0.3,0) -- (2.5,0) node[right,font=\small] {$x$};
    \draw[->] (0,-0.3) -- (0,1.5) node[above,font=\small] {$y$};
    \node[below left,font=\small] at (0,0) {$O$};
    % x0刻度与竖直辅助虚线
    \draw (0.8,-0.05) -- (0.8,0.05) node[below,font=\small] {$x_0$};
    \draw[dashed,gray] (0.8,0) -- (0.8,0.63);
    % 一元函数曲线 y=0.3x²-0.2x+0.6
    \draw[thick,smooth,samples=100,domain=0:2] plot(\x, {0.3*\x*\x - 0.2*\x + 0.6});
    % x0处的切线 y=0.28x+0.41
    \draw[thick,red,domain=0:1.8] plot(\x, {0.28*\x + 0.41});
    % 切点标记
    \fill (0.8,0.63) circle (1pt);
\end{tikzpicture}
\end{document}
```
#### 2. 二元函数对$x$偏导数的几何意义3D示意图
```tikz
\begin{document}
\definecolor{surfgray}{rgb}{0.7,0.7,0.7}
\begin{tikzpicture}[x=1cm,y=1cm,>=stealth,scale=1.2,
 x={(-0.7cm,-0.3cm)}, y={(1cm,-0.2cm)}, z={(0cm,1cm)}]
    % axes
    \draw[->] (0,0,0) -- (2.5,0,0) node[below left,font=\small] {$x$};
    \draw[->] (0,0,0) -- (0,2.5,0) node[right,font=\small] {$y$};
    \draw[->] (0,0,0) -- (0,0,2.5) node[above,font=\small] {$f(x,y)$};
    \node[below left,font=\small] at (0,0,0) {$O$};

    % cutting plane y=1, drawn FIRST
    \fill[blue!10,opacity=0.5] (0,1,0) -- (2,1,0) -- (2,1,2.3) -- (0,1,2.3) -- cycle;
    \draw[blue!40,thin] (0,1,0) -- (2,1,0) -- (2,1,2.3) -- (0,1,2.3) -- cycle;

    % surface mesh
    \foreach \y in {0,0.3,...,1.8,2} {
        \draw[surfgray,thin,smooth,samples=15,domain=0:2]
            plot (\x, \y, {2 - 0.3*((\x-1)*(\x-1) + (\y-1)*(\y-1))});
    }
    \foreach \x in {0,0.3,...,1.8,2} {
        \draw[surfgray,thin,smooth,samples=15,variable=\y,domain=0:2]
            plot (\x, \y, {2 - 0.3*((\x-1)*(\x-1) + (\y-1)*(\y-1))});
    }

    % section curve at y=1
    \draw[thick,black,smooth,samples=30,domain=0:2]
        plot (\x, 1, {2 - 0.3*(\x-1)*(\x-1)});

    % tangent at (0.5,1,1.925), slope fx=0.3
    \draw[thick,red] (0,1,1.775) -- (1.8,1,2.315);

    % tangent point + projection
    \fill (0.5,1,1.925) circle (1.4pt);
    \fill (0.5,1,0) circle (1pt);
    \draw[dashed,gray] (0.5,1,0) -- (0.5,1,1.925);
    \node[font=\small] at (0.42,0.68,0) {$(x_0,y_0)$};

    % point x0+dx=1.3
    \fill (1.3,1,0) circle (1pt);
    \draw[dashed,gray] (1.3,1,0) -- (1.3,1,1.973);
    \node[font=\small] at (1.5,1.3,0) {$(x_0+\Delta x,y_0)$};

    % dx dimension
    \draw[<->,thick] (0.5,1,-0.25) -- (1.3,1,-0.25) node[midway,below,font=\small] {$\Delta x$};

    % angle alpha INSIDE plane y=1, parametric arc (cos/sin take degrees)
    \draw[thick] (0.5,1,1.925) -- (0.8,1,1.925);
    \draw[thick,smooth,samples=20,domain=0:16.7]
        plot ({0.5+0.3*cos(\x)},1,{1.925+0.3*sin(\x)});
    \node[font=\small] at (0.95,1,2.0) {$\alpha$};
\end{tikzpicture}
\end{document}
```

### 补充优化图：x/y方向偏导数几何意义对比
同时展示平行于$xOz$、$yOz$的两个截平面与对应的切线，直观对比两个方向偏导数的几何区别：
```tikz
\begin{document}
\definecolor{surfgray}{rgb}{0.75,0.75,0.75}
\definecolor{planex}{rgb}{0.3,0.6,0.9}
\definecolor{planey}{rgb}{0.9,0.4,0.4}
\begin{tikzpicture}[x=1cm,y=1cm,>=stealth,scale=1.0,
 x={(-0.7cm,-0.3cm)}, y={(1cm,-0.2cm)}, z={(0cm,1cm)}]
    % 坐标轴
    \draw[->] (0,0,0) -- (2.5,0,0) node[below left,font=\small] {$x$};
    \draw[->] (0,0,0) -- (0,2.5,0) node[right,font=\small] {$y$};
    \draw[->] (0,0,0) -- (0,0,2.5) node[above,font=\small] {$z=f(x,y)$};
    \node[below left,font=\small] at (0,0,0) {$O$};

    % 曲面网格（顶点在(1,1,2)的椭圆抛物面）
    \foreach \y in {0,0.4,...,2} {
        \draw[surfgray,thin,smooth,samples=12,domain=0:2]
            plot (\x, \y, {2 - 0.3*((\x-1)*(\x-1) + (\y-1)*(\y-1))});
    }
    \foreach \x in {0,0.4,...,2} {
        \draw[surfgray,thin,smooth,samples=12,variable=\y,domain=0:2]
            plot (\x, \y, {2 - 0.3*((\x-1)*(\x-1) + (\y-1)*(\y-1))});
    }

    % x方向截平面y=1，截线与切线
    \def\xp{0.6}
    \def\yp{1}
    \def\zp{2 - 0.3*((\xp-1)*(\xp-1))}
    \def\fxp{-0.6*(\xp-1)}
    \fill[planex!10,opacity=0.4] (0,\yp,0) -- (2,\yp,0) -- (2,\yp,2.3) -- (0,\yp,2.3) -- cycle;
    \draw[planex!60,thin] (0,\yp,0) -- (2,\yp,0) -- (2,\yp,2.3) -- (0,\yp,2.3) -- cycle;
    \draw[thick,planex,smooth,samples=30,domain=0:2]
        plot (\x, \yp, {2 - 0.3*((\x-1)*(\x-1))});
    \draw[thick,planex!80!black] ({\xp-0.5}, \yp, {\zp + \fxp*(-0.5)}) -- ({\xp+1.2}, \yp, {\zp + \fxp*1.2})
        node[right,font=\small] {$f_x$ tangent};

    % y方向截平面x=1，截线与切线
    \def\xq{1}
    \def\yq{0.6}
    \def\zq{2 - 0.3*((\yq-1)*(\yq-1))}
    \def\fyq{-0.6*(\yq-1)}
    \fill[planey!10,opacity=0.4] (\xq,0,0) -- (\xq,2,0) -- (\xq,2,2.3) -- (\xq,0,2.3) -- cycle;
    \draw[planey!60,thin] (\xq,0,0) -- (\xq,2,0) -- (\xq,2,2.3) -- (\xq,0,2.3) -- cycle;
    \draw[thick,planey,smooth,samples=30,variable=\y,domain=0:2]
        plot (\xq, \y, {2 - 0.3*((\y-1)*(\y-1))});
    \draw[thick,planey!80!black] (\xq,{\yq-0.5}, {\zq + \fyq*(-0.5)}) -- (\xq,{\yq+1.2}, {\zq + \fyq*1.2})
        node[above right,font=\small] {$f_y$ tangent};

    % 顶点标记
    \fill (1,1,2) circle (1.5pt) node[above right,font=\small] {$(x_0,y_0,f(x_0,y_0))$};
    \fill (1,1,0) circle (1pt);
    \draw[dashed,gray] (1,1,0) -- (1,1,2);
    \node[below,font=\small] at (1,1,0) {$(x_0,y_0)$};

\end{tikzpicture}
\end{document}
```
所有代码均遵循TikZJax渲染规则：无中文节点、坐标运算使用花括号包裹、采样数控制在低算力范围，可直接在Obsidian TikZJax插件中渲染。
