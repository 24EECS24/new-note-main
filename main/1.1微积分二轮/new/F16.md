     3. 二阶导数定义：函数$f(x)$在$x_0$处的二阶导数是其一阶导数在$x_0$处的变化率，给出$\Delta x\to0$和$x\to x_0$两种极限形式

     4. 结论的证明过程：通过二阶导数的极限定义推导$\lim_{x\to x_0}[f'(x)-f'(x_0)]=0$，证明一阶导的连续性

### 补充：高阶导数物理意义示意图（对应笔记开头位移-速度-加速度引入）
```tikz
\begin{document}
\definecolor{sblue}{rgb}{0.1,0.3,0.8}
\definecolor{vred}{rgb}{0.8,0.2,0.2}
\definecolor{agreen}{rgb}{0.1,0.6,0.1}
\begin{tikzpicture}[x=1.8cm,y=0.7cm,scale=1.1]
    % 坐标轴
    \draw[->] (-0.3,0) -- (2.3,0) node[right,font=\small] {$t$};
    \draw[->] (0,-0.5) -- (0,4.5);
    \node[below left,font=\small] at (0,0) {$O$};
    % 刻度标记
    \draw (1,-0.08) -- (1,0.08) node[below,font=\small] {$1$};
    \draw (2,-0.08) -- (2,0.08) node[below,font=\small] {$2$};
    \draw (-0.08,2) -- (0.08,2) node[left,font=\small] {$2$};
    \draw (-0.08,4) -- (0.08,4) node[left,font=\small] {$4$};
    % 位移函数 s(t) = t^2 （蓝色：0阶导，位移）
    \draw[line width=0.8pt,color=sblue,smooth,samples=80,domain=0:2] 
        plot(\x,{\x*\x}) node[above right,font=\small] {$s(t)$};
    % 速度函数 v(t) = s'(t) = 2t （红色：1阶导，位移的变化率）
    \draw[line width=0.8pt,color=vred,smooth,samples=80,domain=0:2] 
        plot(\x,{2*\x}) node[above right,font=\small] {$v(t)=s'(t)$};
    % 加速度函数 a(t) = v'(t) = s''(t) = 2 （绿色：2阶导，速度的变化率）
    \draw[line width=0.8pt,color=agreen,smooth,samples=80,domain=0:2] 
        plot(\x,{2}) node[above right,font=\small] {$a(t)=s''(t)$};
    % 辅助虚线展示t=1处的各阶导数值
    \draw[dashed,gray] (1,0) -- (1,1);
    \draw[dashed,gray] (1,0) -- (1,2);
    \fill[sblue] (1,1) circle (1.2pt);
    \fill[vred] (1,2) circle (1.2pt);
    \fill[agreen] (1,2) circle (1.2pt);
\end{tikzpicture}
\end{document}
```
*示意图说明：蓝色曲线为位移函数$s(t)=t^2$，红色直线为速度函数$v(t)=s'(t)=2t$（位移的一阶导，即$s(t)$的切线斜率），绿色水平线为加速度$a(t)=s''(t)=2$（速度的一阶导，即$v(t)$的切线斜率），直观展示高阶导数是“变化率的变化率”。*

### 补充：高阶导数几何意义示意图（对应二阶导数与曲线凹凸性）
```tikz
\begin{document}
\definecolor{fblue}{rgb}{0.1,0.3,0.8}
\definecolor{fpred}{rgb}{0.8,0.2,0.2}
\definecolor{fppgreen}{rgb}{0.1,0.6,0.1}
\begin{tikzpicture}[x=1.5cm,y=1.5cm,scale=1.0]
    % 坐标轴
    \draw[->] (-1.5,0) -- (1.5,0) node[right,font=\small] {$x$};
    \draw[->] (0,-0.5) -- (0,2.5) node[above,font=\small] {$y$};
    \node[below left,font=\small] at (0,0) {$O$};
    % 刻度
    \draw (-1,-0.08) -- (-1,0.08) node[below,font=\small] {$-1$};
    \draw (1,-0.08) -- (1,0.08) node[below,font=\small] {$1$};
    \draw (-0.08,1) -- (0.08,1) node[left,font=\small] {$1$};
    \draw (-0.08,2) -- (0.08,2) node[left,font=\small] {$2$};
    % 原函数 f(x)=x²（凹函数）
    \draw[line width=0.8pt,color=fblue,smooth,samples=80,domain=-1.2:1.2] 
        plot(\x,{\x*\x}) node[above right,font=\small] {$f(x)=x^2$};
    % 一阶导 f'(x)=2x（原函数的切线斜率函数）
    \draw[line width=0.8pt,color=fpred,smooth,samples=80,domain=-1.2:1.2] 
        plot(\x,{2*\x}) node[above right,font=\small] {$f'(x)=2x$};
    % 二阶导 f''(x)=2（一阶导的斜率，对应原函数凹凸性：f''>0为凹函数）
    \draw[line width=0.8pt,color=fppgreen,smooth,samples=80,domain=-1.2:1.2] 
        plot(\x,{2}) node[above right,font=\small] {$f''(x)=2$};
    % 展示x=0.5处的切线：斜率为f'(0.5)=1
    \draw[dashed,gray] (0.5,0) -- (0.5,0.25);
    \draw[line width=0.6pt,gray] (0,0) -- (1,1) node[right,font=\small] {tangent at $x=0.5$};
\end{tikzpicture}
\end{document}
```
*示意图说明：蓝色抛物线为原函数$f(x)=x^2$，红色直线为其一阶导$f'(x)=2x$（描述原函数切线斜率的变化），绿色水平线为其二阶导$f''(x)=2$（描述斜率的变化速率，$f''(x)>0$对应原函数为凹函数）。*
