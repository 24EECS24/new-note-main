# 复合函数与定义域·值域 知识总结

> 本文把《复合函数》笔记的「层符号通法框架」与《函数的定义域与值域》笔记的「题型细节 + 速查表」合并去重：以「层」为核心，把**定义域、值域、对应法则**三个问题统一到同一套符号体系下，形成可速查、可迁移的通法总结。

---

## 〇、核心框架：复合函数 = 内层 + 外层

### 1. 二层复合的符号模型

$$
\begin{align*}
&若\quad D_{a} \xrightarrow{\ a(\ )\ } R_{a}\quad(\text{第一层：内层})\\[4pt]
&\qquad D_{b} \xrightarrow{\ b(\ )\ } R_{b}\quad(\text{第二层：外层})\\[4pt]
&\qquad D \xrightarrow{\ b[a(\ )]\ } R\\[4pt]
&\text{则有}\quad \boxed{\ D=D_{a}\cap a^{-1}(D_{b})\ }\qquad \boxed{\ R=b\big[R_{a}\cap D_{b}\big]\ }
\end{align*}
$$

> **关键认知**：无论求定义域还是求值域，都从各层的定义域 $D_a$、$D_b$ 入手；而 $D_a$、$D_b$ 往往能直接写出（基本初等函数的定义域见 §一.2）。

### 2. 求定义域 / 求值域的本质

| 问题 | 方向 | 本质 |
|---|---|---|
| 求定义域 $D$ | 由外向内 | 用外层定义域 $D_b$ 反解出允许输入 $\Box$，再与内层定义域 $D_a$ 取交集 |
| 求值域 $R$ | 由内向外 | 内层值域 $R_a$ 与外层定义域 $D_b$ 取交集，得到外层有效输入，再经外层输出 |

> 一句话：**定义域「由外向内卡」，值域「由内向外流」**。

## 一、求定义域

### 1. 核心思路

$$
\begin{align*}
&求 f(x) 的定义域，本质是找让整个式子「有意义」的所有 x \\[4pt]
\bullet \quad &先逐个找出每个会限制定义域的「关键点」（分母、根号、对数、反三角等）\\[4pt]
\bullet \quad &再看区间边界能否取到（等号是否成立）\\[4pt]
\bullet \quad &最后把各个条件求得的区间取**交集**（最终区间必须同时满足整个式子）
\end{align*}
$$

### 2. 基本初等函数的定义域速查

| 函数 | 定义域 |
|---|---|
| $\ln x$ | $x>0$ |
| $\sqrt{x}$ | $x\ge 0$ |
| $\dfrac{1}{x}$ | $x\ne 0$ |
| $\dfrac{1}{\ln x}$ | $x>0$ 且 $x\ne 1$ |
| $\dfrac{1}{\sqrt{x}}$ | $x>0$ |
| $\ln\ln x$ | $x>1$ |
| $\dfrac{1}{\ln\ln x}$ | $x>1$ 且 $x\ne e$ |
| $\arcsin x$、$\arccos x$ | $x\in[-1,1]$ |
| $\arctan x$ | $x\in \mathbb{R}$ |

### 3. 复合函数求定义域：由外向内拆层

对于 $y=b\big[a(x)\big]$，即 $y=f\big[g(x)\big]$：

$$
\begin{align*}
&1.\ \text{外层 } b(\ ) \text{ 的输入必须落在 } D_b \text{ 内}，\text{反解出内层 } a(x) \text{ 允许的取值范围 } \Box \\[4pt]
&2.\ \text{内层 } a(x) \text{ 本身有定义域 } D_a \\[4pt]
&3.\ \text{取交集 } D = D_a \cap \Box
\end{align*}
$$

**例** 求 $y=\sqrt{\ln x}$ 的定义域：

$$
\begin{align*}
&\text{内层 } a(x)=\ln x \Rightarrow D_a=(0,+\infty) \\[4pt]
&\text{外层 } b(t)=\sqrt{t} \Rightarrow D_b=[0,+\infty) \\[4pt]
&\text{令 } \ln x\ge 0 \Rightarrow x\ge 1，\text{即 } \Box=[1,+\infty) \\[4pt]
&\therefore D = (0,+\infty)\cap[1,+\infty) = [1,+\infty)
\end{align*}
$$

### 4. 抽象函数 $f(\Box)$ 的定义域：对应法则决定输入范围

**核心**

$$
\begin{align*}
&定义域 \xrightarrow{\text{是指}} 自变量 x 的取值范围 \\[4pt]
\bullet \quad &不同函数里的自变量 x 取值不一定相同 \\[4pt]
\bullet \quad &只要对应法则 f(\ \ ) 相同，则括号 (\ \ ) 的输入范围相同
\end{align*}
$$

**步骤**（已知 $f(\Box_1)$ 的定义域，求 $f(\Box_2)$ 的定义域）

$$
\begin{align*}
&1.\ 由 f(\Box_1) 的定义域 \Rightarrow 求出 \Box_1 的取值范围（= f 的输入范围）\\[4pt]
&2.\ 令 \Box_2 落在同一输入范围内 \\[4pt]
&3.\ 解出 x 的范围
\end{align*}
$$

**例**

$$
\begin{align*}
&f(\ln x) 的定义域为 [1,e] \Rightarrow \ln x\in[0,1] \\[4pt]
&\Rightarrow f(\ \ ) 的输入范围是 [0,1] \\[4pt]
&\therefore e^x\in[0,1] \Rightarrow x\in(-\infty,\ 0]
\end{align*}
$$

> 注：$y=f(x)$ 中 $x$ 是自变量；$y=f(3+e^x)$ 中 $3+e^x$ 是中间变量、$x$ 才是自变量，但二者作为 $f$ 的输入范围相同。

### 5. 易错点

- 边界开闭要分清：$\dfrac{1}{\sqrt{x}}$ 要求 $x>0$，而不是 $x\ge 0$；
- 最终取**交集**，不是并集；
- 嵌套对数逐层挖：$\ln\ln x$ 先要求 $\ln x>0$，再推出 $x>1$。

## 二、求值域

### 1. 复合函数求值域：由内向外拆层

核心公式：$\ R = b\big[R_a\cap D_b\big]\ $，即「内层值域 ∩ 外层定义域 → 再经外层输出」。

`````col
````col-md
flexGrow=1
===
**基础法（先求定义域）：**
$$
\begin{align*}
&1.\ 先求出定义域 D \\[4pt]
&2.\ 由 D 作内层输入，求内层值域 R_a \\[4pt]
&3.\ 取 R_a\cap D_b 为外层有效输入 \\[4pt]
&4.\ 经外层输出得 R
\end{align*}
$$
````
````col-md
flexGrow=1
===
**进阶法（直接算值域）：**
$$
\begin{align*}
&1.\ 由 D_a 作内层输入，直接求 R_a \\[4pt]
&2.\ 与 D_b 取交集得 R_a\cap D_b \\[4pt]
&3.\ 经外层输出得 R
\end{align*}
$$
````
`````

**例**

$$
y=\ln\!\left(\frac{x}{x-1}\right)\ \text{ 由 } y=\ln t \text{ 与 } t=\frac{x}{x-1} \text{ 复合}
$$

$$
\begin{align*}
&\text{内层 } t=\frac{x}{x-1}=1+\frac{1}{x-1}，x\ne 1 \\[4pt]
&\Rightarrow t\in(-\infty,1)\cup(1,+\infty) \\[4pt]
&\text{外层 } \ln(\ )\text{ 要求 } t>0 \Rightarrow t\in(0,1)\cup(1,+\infty) \\[4pt]
&\Rightarrow y=\ln t\in(-\infty,0)\cup(0,+\infty) \\[4pt]
&\quad (t\to 1 \text{ 时 } \ln t\to 0，\text{故 } y\ne 0)
\end{align*}
$$

### 2. 单调函数：定义域 ↔ 值域互求

`````col
````col-md
flexGrow=1
===
**单调时：**
$$
\begin{align*}
&可直接把区间边界代入 \\[4pt]
&得到所求区间的边界 \\[4pt]
&若边界取不到（开区间）\\[4pt]
&就取极限
\end{align*}
$$
````
````col-md
flexGrow=1
===
**不单调时：**
$$
\begin{align*}
&要多算一下 \\[4pt]
&极大值与极小值
\end{align*}
$$
````
`````

**例**

$$
\begin{align*}
&\because \arctan x \text{ 在 } (0,1) \text{ 上单调} \\[4pt]
&\therefore \arctan x \text{ 的边界 } 0,1 \text{ 对应 } x \text{ 的边界 } 0,\ \tan 1 \\[4pt]
&\text{且边界取不到 } \Rightarrow x\in(0,\ \tan 1)
\end{align*}
$$

### 3. 常用技巧

- **分式拆分**：$\dfrac{x}{x-1}=1+\dfrac{1}{x-1}$；
- **单调性 + 极限**求边界；
- **同号取倒必变号**：

$$
\begin{align*}
&若\ a>b>0，则\ \frac{1}{a}<\frac{1}{b} \\[4pt]
&若\ a<b<0，则\ \frac{1}{a}>\frac{1}{b} \\[4pt]
&若\ a>0,\ b<0，则\ a>b\ 且\ \frac{1}{a}>\frac{1}{b}
\end{align*}
$$

## 三、求对应法则：由复合函数反求外层（或最外层）

> 问题形式：已知复合函数 $w(\ )$ 与内层（若干层），求外层 $b(\ )$（或最外层 $c(\ )$）。

### 1. 二层复合：给出 $w(\ )=b\big[a(\ )\big]$ 与 $a(\ )$，求 $b(\ )$

`````col
````col-md
flexGrow=1
===
**法1：反函数代入法**
$$
\begin{align*}
&由 a(\ ) 求出 a^{-1}(\ ) \\[4pt]
&b(\ )=w\big[a^{-1}(\ )\big]
\end{align*}
$$
````
````col-md
flexGrow=1
===
**法2：配凑法**
$$
\begin{align*}
&若 a(\ ) 没有全局反函数，\\[4pt]
&或 a^{-1}(\ ) 不好求 \\[4pt]
&用平方差、完全平方的逆运算等恒等变形 \\[4pt]
&直接在 w(\ ) 中凑出 a(\ )，得 b(\ )
\end{align*}
$$
````
`````

### 2. 三层复合：给出 $w(\ )=c\big[b\big[a(\ )\big]\big]$ 与 $a(\ )、b(\ )$，求 $c(\ )$

`````col
````col-md
flexGrow=1
===
**法1：反函数剥离法**
$$
\begin{align*}
&若 a、b 均为一一对应函数 \\[4pt]
&连续两次反函数代入，逐层向内剥离 \\[4pt]
&先剥离第二层 b，再剥离第一层 a \\[4pt]
&c(\ )=w\big[a^{-1}\big[b^{-1}(\ )\big]\big]
\end{align*}
$$
````
````col-md
flexGrow=1
===
**法2：逐层配凑法**
$$
\begin{align*}
&若内层无全局反函数，或反函数不好求 \\[4pt]
&利用恒等变形，逐层构造内层整体 \\[4pt]
&先在 w(\ ) 中凑出 b(\ ) 的整体 \\[4pt]
&再进一步凑出 a(\ ) 的整体 \Rightarrow c(\ )
\end{align*}
$$
````
`````

$$
a^{b}=N \ \Longleftrightarrow\ \log_{a}N=b
\qquad\qquad

\qquad
\arccos x \in \left[0,\ \pi\right]
\qquad
\arctan x \in \left(-\frac{\pi}{2},\ \frac{\pi}{2}\right)

$$
\frac{1}{\cos x}=\sec x
\qquad
\frac{1}{\sin x}=\csc x
\qquad

$$

## 五、总结速查

- **求定义域**：找限制点 → 判边界开闭 → 各条件区间取**交集**；
- **复合函数求定义域**：**由外向内**，$D=D_a\cap a^{-1}(D_b)$；
- **复合函数求值域**：**由内向外**，$R=b\big[R_a\cap D_b\big]$；
- **抽象函数 $f(\Box)$**：定义域指 $x$ 范围，同一 $f$ 的 $\Box$ 输入范围相同；
- **单调函数互求定义域/值域**：代入边界或取极限；不单调则算极值；
- **求对应法则**：能求反函数就反函数剥离，否则恒等变形配凑内层整体。
