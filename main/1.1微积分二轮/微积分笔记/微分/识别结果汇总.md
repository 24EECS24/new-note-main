## 二元函数的导函数
### 偏导函数
将$z = g(y,x)$中的一个变量视为某一常数，再对另一变量求导，称为偏导。

将$x$视为常数：
则$z = g(y,x) \xlongequal{\text{视为}} h(y)$
求的是$z$随$y$轴（一条直线）变化的变化率。
相当于
$$\lim_{\Delta y \to 0} \frac{\Delta z}{\Delta y} = \frac{\partial z}{\partial y}$$
记为
$$g'_y(x,y) = \frac{\partial z}{\partial y}$$
将$y$视为常数：
则$z = g(y,x) \xlongequal{\text{视为}} w(x)$
求的是$z$随$x$轴（一条直线）变化的变化率。
相当于
$$\lim_{\Delta x \to 0} \frac{\Delta z}{\Delta x} = \frac{\partial z}{\partial x}$$
记为
$$g'_x(x,y) = \frac{\partial z}{\partial x}$$
### 全导函数

以x为基准量的全导函数
$z = g(y,x)$，$y = f(x)$
则$z = g\left[f(x), x\right] = h(x)$
$$\lim_{\Delta x \to 0} \frac{\Delta z}{\Delta x} = \frac{dz}{dx}$$
求的是$z$随$y=f(x)$这条线变化的变化率，相当于是一元的复合函数求导。
记为$h'(x) = \frac{dz}{dx}$。

当然，以y为基准量的全导函数
由$y=f(x)$可得$x = f^{-1}(y) = h(y)$，$y=f(x)$与$x=h(y)$是同一条路径。
则$z = g\left[y, h(y)\right] = w(y)$
$$ \lim_{\Delta y \to 0} \frac{\Delta z}{\Delta y} = \frac{dz}{dy}$$
求的是$z$随$x=h(y)$这条线变化的变化率。
记为$w'(y) = \frac{dz}{dy}$。

## 求二元全导函数（以 $x$ 为基准量）
$z = g(y,x)$，$y = f(x)$
则$z = g\left[f(x), x\right] = h(x)$
$$\displaystyle h'(x) = \lim_{\Delta x \to 0} \frac{\Delta z}{\Delta x} = \frac{dz}{dx}$$

## 求二元全导函数（以 $y$ 为基准量）
由$y=f(x)$可得$x = f^{-1}(y) = \phi(y)$，$y=f(x)$与$x=\phi(y)$是同一条路径。
则$z = g\left[y, \phi(y)\right] = w(y)$
$$\displaystyle w'(y) = \lim_{\Delta y \to 0} \frac{\Delta z}{\Delta y} = \frac{dz}{dy}$$
求的是$z$随$x=\phi(y)$这条线变化的变化率。
记为
$$\displaystyle w'(y) = \frac{dz}{dy}$$

## 求二元全导函数（以 $t$ 为基准量）
路径参数化：$x = x(t)$，$y = y(t)$
则$z = g\left[y(t),\ x(t)\right] = \varphi(t)$
$$\displaystyle \varphi'(t) = \lim_{\Delta t \to 0} \frac{\Delta z}{\Delta t} = \frac{dz}{dt}$$
求的是$z$随参数路径$\left(x(t),\ y(t)\right)$这条线变化的变化率，相当于一元的复合函数求导，展开为两条链相加：
$$\displaystyle \frac{dz}{dt} = g'_x(x,y)\frac{dx}{dt} + g'_y(x,y)\frac{dy}{dt}$$

## 三个基准量的代数关系（互相换算）
$$\displaystyle \frac{dz}{dx} = \frac{dz}{dy}\cdot\frac{dy}{dx}$$

$$\displaystyle \frac{dz}{dy} = \frac{dz}{dx}\cdot\frac{dx}{dy}$$

$$\displaystyle \frac{dz}{dt} = \frac{dz}{dx}\cdot\frac{dx}{dt} = \frac{dz}{dy}\cdot\frac{dy}{dt}$$

统一规律：任意两个基准量的换算 = 变化率 × 两基准量之间的换算因子。

## 调试验证（例：$z = x^2 + y^2$，路径 $x = t,\ y = t^2$）

**① 直接代入（真值）**：$z = t^2 + t^4$，则 $\frac{dz}{dt} = 2t + 4t^3$

**② 用 $t$ 公式**：$g'_x = 2x$，$g'_y = 2y$，$\frac{dx}{dt} = 1$，$\frac{dy}{dt} = 2t$
$$\displaystyle \frac{dz}{dt} = 2x\cdot 1 + 2y\cdot 2t = 2t + 4t^3 \quad \checkmark$$

**③ 用 $x$ 换算**：$\frac{dz}{dx} = 2x + 4x^3$，$\frac{dx}{dt} = 1$
$$\displaystyle \frac{dz}{dx}\cdot\frac{dx}{dt} = (2t + 4t^3)\times 1 = 2t + 4t^3 \quad \checkmark$$

**④ 用 $y$ 换算**：$\frac{dz}{dy} = 1 + 2y$，$\frac{dy}{dt} = 2t$
$$\displaystyle \frac{dz}{dy}\cdot\frac{dy}{dt} = (1 + 2t^2)\times 2t = 2t + 4t^3 \quad \checkmark$$

四条路结果完全一致，公式与换算关系均验证通过。
