## 导数的定义
$$f'(x_0) = \lim_{\text{增量} \to 0} \frac{f(x_0 + \text{增量}) - f(x_0)}{\text{增量}}$$
唯一要求：**分子里$x_0$旁边加的东西，和分母，必须是同一个「增量」，并且这个增量$\to 0$。**

## 例题
待计算极限：
$$\lim_{\Delta x \to 0} \frac{f(x_0 - 2\Delta x) - f(x_0)}{\Delta x}$$
**第1步 找增量**：看分子$x_0$旁边是谁——是$-2\Delta x$，它才是真正的增量$h$。
**第2步 凑分母**：分母现在是$\Delta x$，把它也变成$-2\Delta x$，外面乘$-2$配平：
$$= -2 \cdot \lim_{\Delta x \to 0} \frac{f(x_0 - 2\Delta x) - f(x_0)}{-2\Delta x}$$
**第3步 套模板**：$\Delta x \to 0$时，增量$-2\Delta x$确实$\to 0$✓，所以这个分式就是$f'(x_0)$：
$$= -2 \cdot f'(x_0)$$

> $\Delta x$是题目原本的变量，$-2\Delta x$只是它的一个表达式。你愿意换元令$h = -2\Delta x$、把下面写成$h \to 0$也完全对——
> $\Delta x \to 0$和$-2\Delta x \to 0$是同一个趋近过程，写哪个都不算错，纯粹是写法习惯。

## 结论：「只要增量能$\to 0$就行」——你是对的
已知$f'(x_0)$存在时，增量$h$想写成什么都可以，只要$\Delta x \to 0$时它跟着$\to 0$：

| 增量$h$写成 | $\Delta x \to 0$时$h$是否$\to 0$ | 能否套模板 |
| ----- | ----- | ----- |
| $h=-2\Delta x$ | 是 | ✓ |
| $h=\Delta x^2$ | 是 | ✓ |
| $h=\Delta x^3$ | 是 | ✓ |
| $h=\sin\Delta x$ | 是 | ✓ |

> 为什么单向就够？$f'(x_0)$存在本身的含义就是：增量$h$无论从左边、右边、以什么速度、走哪条路径趋于0，这个商都收敛到同一个数$f'(x_0)$。既然条条大路都到同一个值，你随便挑一条会$\to0$的路（$-2\Delta x$、$\Delta x^2$……）当然都得到它——不需要可逆，不需要双向。

## 澄清：之前那个$|h|/h$反例，为什么跟本题无关
| 反例的前提：$|h|/h$的双侧极限本来就不存在（左边-1、右边+1，对不上）。极限都不存在，换个趋近条件，值当然可能变——它说明的是“极限不存在时别乱换条件”。 | 做题的前提：题目里$f'(x_0)$存在且唯一，左右早已相等。前提根本不同，反例打不到这道题。可以直接忘掉它，不必再纠结$h \to 0^+$。 |
| ----- | ----- |

> **做题口诀**：找增量 → 分母凑成同一个增量 → 乘系数配平 → 增量趋于0就套$f'(x_0)$
> 增量怎么写都行，只要它$\to 0$；单向足够，双向/可逆都不是你需要操心的事。
