
# 奇偶性

## 定义 
是奇函数/偶函数的前提是，函数定义域D关于原点对称
- 奇函数：$f(-x)=-f(x)$，图象关于**原点**对称。
- 偶函数：$f(-x)=f(x)$，图象关于 **$y$ 轴**对称。

**eg**：判断$f(x)+f(-x)$与$f(x)-f(-x)$的奇偶性

**解析**：令 $F(x)=f(x)+f(-x)$，$W(x)=f(x)-f(-x)$

## 求导结论： 
可导偶函数的导函数是奇函数，即**每求一次导，函数奇偶性互换**。

$f(x)$是偶函数，证明：$f'(-x) = -f'(x)$ 
由导数定义：
$$
f'(-x) = \lim_{\Delta x \to 0} \frac{f(-x+\Delta x) - f(-x)}{\Delta x}
$$
因$f(x)$是偶函数，满足$f(-x)=f(x)$，代入得：
$$
= \lim_{\Delta x \to 0} \frac{f(x-\Delta x) - f(x)}{\Delta x}
$$
对极限式做恒等变形，凑导数定义形式：
$$
= -\lim_{\Delta x \to 0} \frac{f(x+(-\Delta x)) - f(x)}{-\Delta x}= -f'(x)
$$

## 重要函数奇偶性

$\displaystyle y=\ln(x+\sqrt{1+x^2})$ 是**奇函数** 
$\displaystyle y=\ln(x+\sqrt{1+x^2})$的反函数是**双曲正弦** $\sinh x$ 

$\dfrac{e^x-1}{e^x+1}$：这是**双曲正切**型**奇函数** 

**含绝对值**：$|x|$ 是偶函数，$f(|x|)$ 恒为偶函数

$f(x)+f(-x)$ 恒为**偶函数** 
$f(x)-f(-x)$ 恒为**奇函数** 



# 单调性
## 单调性的判别
设函数$y=f(x)$在$[a,b]$上连续，在$(a,b)$内可导。

严格单调（充要形式）

$$f\ \text{在}\ [a,b]\ \text{严格单调增加} \iff f'(x)\ge 0\ \text{于}\ (a,b)，且\ f'\ \text{不在任何长度大于 0 的子区间上恒等于}\ 0$$

$$f\ \text{在}\ [a,b]\ \text{严格单调减少} \iff f'(x)\le 0\ \text{于}\ (a,b)，且\ f'\ \text{不在任何长度大于 0 的子区间上恒等于}\ 0$$


**理解**：“$f'(x)不在任何长度大于 0 的子区间上恒等于 0$”

例1：$f(x)=x^4$在$x=0$这一点的变化率

- $f'(0)=0$：$f(x)$ 在 x=0 这一个点的瞬时变化率为 0；
- 但 $f'(x)=4x^3$ 不恒为 0，在 0 两侧变号 
  即，f 的变化率在 0 附近是在变化的；
  
$$
\begin{align*}

&\begin{cases}
(0-\varphi, 0)， f'(x) <0 \\[4pt]
x = 0， f'(x) =0 \\[4pt]
(0, 0+\varphi)， f'(x) >0
\end{cases}\\[6pt]

\because &f{(x)}' 只在x=0这一点处为0，\\[6pt]
&即:f'(x)不在任何长度大于 0 的子区间上恒等于 0 \\[6pt]
\therefore& \\[6pt]
&在(0-\varphi,0]上， f'(x) <0  \implies f(x)严格递减\\[6pt]
&在[0,0+\varphi)上， f'(x) >0 \implies f(x)严格递增\\[6pt]

\end{align*}
$$

例2：
函数 $y=x^3$ 在 $(-\infty,+\infty)$ 上连续且可导，

则函数 $y=x^3$ 在 $(-\infty,+\infty)$ 上严格单调增加。
