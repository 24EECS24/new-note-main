

| 类别   | 公式                                                                                               |
| ---- | ------------------------------------------------------------------------------------------------ |
| 基本关系 | $$\displaystyle \sin^2x+\cos^2x=1$$                                                              |
| 基本关系 | $$\displaystyle \tan x=\frac{\sin x}{\cos x},\qquad 1+\tan^2x=\sec^2x$$                          |
| 二倍角  | $$\displaystyle \sin2x=2\sin x\cos x$$                                                           |
| 二倍角  | $$\displaystyle \cos2x=\cos^2x-\sin^2x=2\cos^2x-1=1-2\sin^2x$$                                   |
| 和差化积 | $$\displaystyle \sin A\pm\sin B=2\sin\frac{A\pm B}{2}\cos\frac{A\mp B}{2}$$                      |
| 辅助角  | $$\displaystyle a\sin x+b\cos x=\sqrt{a^2+b^2}\,\sin(x+\varphi),\qquad \tan\varphi=\frac{b}{a}$$ |
| 高频恒等 | $$\displaystyle \frac{1}{\sin x\cos x}=\frac{2}{\sin2x}$$                                        |
