





分析：
看到要证$f(\xi)=1-\xi$，
则将常量$\xi$变量化，得到$f(x)=1-x$。
可设$g(x)=f(x)+x$，则证出$g(\xi)=1$即可，此时考虑使用拉格朗日中值定理；
但拉格朗日中值定理建立的是$f(x)$与$f'(x)$的关系，我们未知$f'(x)$的信息，故排除该思路。
重新设$g(x)=f(x)+x-1$，则证出$g(\xi)=0$即可；
要证函数值为0，可考虑费马引理、罗尔定理、零点定理：
其中费马引理、罗尔定理都需要导数相关条件，只有零点定理无需$f'(x)$的信息；
且$g(0)=-1$与$g(1)=1$异号，因此可以用零点定理证明。


证明：
设$g(x)=f(x)+x-1$。
$\because f(x)$在$[0,1]$上连续，在$(0,1)$内可导，
且$g(0)=-1$，
$g(1)=1$，
$\therefore g(0)\cdot g(1)<0$。
$\therefore \exists \xi \in [0,1]$，使得
$$g(\xi)=0$$
即
$$f(\xi)+\xi-1=0$$
$$f(\xi)=1-\xi$$
