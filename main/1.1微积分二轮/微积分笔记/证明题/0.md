


# 涉及函数的中值定理

设$f(x)$在$[a,b]$上连续，则有以下定理：
## 有界与最值定理

$x\in[a,b]$，则有$m \leq f(x) \leq M$
($m,M$分别为$f(x)$在$[a,b]$上的最小值与最大值)
## 介值定理

`````col
````col-md
flexGrow=1.1
===

若$y=\mu$满足$\mu \in [m,M]$，

则存在$x=\xi \in [a,b]$，使得$f(\xi)=\mu$。

即水平直线$y=\mu$与
曲线$y=f(x)$在$[a,b]$上至少有一个交点。
`````

## 平均值定理

区间$(a,b)$：

```tikz
\begin{document}
\definecolor{curveblue}{rgb}{0.2,0.3,0.8}
\begin{tikzpicture}[>=stealth,scale=1.2]
    % Interval line
    \draw[line width=0.8pt,curveblue] (0,0) -- (4,0);
    % End point ticks
    \draw[line width=0.8pt,curveblue] (0,0.1) -- (0,-0.1) node[below,font=\small] {$a$};
    \draw[line width=0.8pt,curveblue] (4,0.1) -- (4,-0.1) node[below,font=\small] {$b$};
\end{tikzpicture}
\end{document}
```
在区间内插入$n$个分点，满足$a < x_1 < x_2 < \dots < x_n < b$：

```tikz
\begin{document}
\definecolor{curveblue}{rgb}{0.2,0.3,0.8}
\begin{tikzpicture}[>=stealth,scale=1.2]
    % Interval line
    \draw[line width=0.8pt,curveblue] (0,0) -- (6,0);
    % End point ticks
    \draw[line width=0.8pt,curveblue] (0,0.1) -- (0,-0.1) node[below,font=\small] {$a$};
    \draw[line width=0.8pt,curveblue] (6,0.1) -- (6,-0.1) node[below,font=\small] {$b$};
    % Division points
    \def\xone{1}
    \def\xtwo{2}
    \def\xn{5}
    \draw[line width=0.8pt,curveblue] (\xone,0.1) -- (\xone,-0.1) node[below,font=\small] {$x_1$};
    \draw[line width=0.8pt,curveblue] (\xtwo,0.1) -- (\xtwo,-0.1) node[below,font=\small] {$x_2$};
    \draw[line width=0.8pt,curveblue] (\xn,0.1) -- (\xn,-0.1) node[below,font=\small] {$x_n$};
    % Dots for omitted points
    \node[font=\small] at (3.5,0) {$\dots$};
\end{tikzpicture}
\end{document}
```
则在$[x_1,x_n]$内至少存在一点$x=\xi$，使得

$$
f(\xi) = \frac{f(x_1)+f(x_2)+\dots +f(x_n)}{n}
$$

## 零点定理

若$f(x)$在闭区间$[a,b]$上连续
且$f(a)\cdot f(b)<0$（即端点函数值异号，负数$<0<$正数）
则$\exists \xi\in(a,b)$，使得$f(\xi)=0$。

```tikz
\begin{document}
\definecolor{curveblue}{rgb}{0.2,0.3,0.8}
\begin{tikzpicture}[x=1.5cm,y=1.5cm,>=stealth,scale=1.2]
    % Axes (y extends below zero)
    \draw[->] (-0.3,0) -- (3.8,0) node[right,font=\small] {$x$};
    \draw[->] (0,-1.3) -- (0,1.5) node[above,font=\small] {$y$};
    \node[below left,font=\small] at (0,0) {$O$};
    % Tick labels a, b
    \draw (1,0) node[below,font=\small] {$a$} -- (1,0.05);
    \draw (3,0) node[below,font=\small] {$b$} -- (3,0.05);
    % Curve f(x)=0.15(x-2)^3+0.5(x-2): f(1)=-0.65<0, f(3)=0.65>0, root xi=2
    \draw[line width=0.8pt,curveblue,smooth,samples=100,domain=1.0:3.0]
        plot(\x,{0.15*(\x-2)*(\x-2)*(\x-2) + 0.5*(\x-2)});
    % Root point and endpoints
    \fill (2,0) circle (1.2pt) node[below right,font=\small] {$\xi$};
    \fill (1,-0.65) circle (1.2pt) node[below left,font=\small] {$(a,f(a))$};
    \fill (3,0.65) circle (1.2pt) node[above right,font=\small] {$(b,f(b))$};
    % Dashed projections
    \draw[dashed,gray] (1,0) -- (1,-0.65);
    \draw[dashed,gray] (3,0) -- (3,0.65);
    % Label
    \node[right,font=\small] at (2.1,0.3) {$f(\xi)=0$};
\end{tikzpicture}
\end{document}
```

若$f(x)$在开区间$(a,b)$内连续，
$\displaystyle \lim_{x\to a^+}f(x)=\alpha，\lim_{x\to b^-}f(x)=\beta，且\alpha\cdot\beta<0$，
则$\exists \xi\in(a,b)$，使得$f(\xi)=0$。

($a,b,\alpha,\beta$可以是有限数，也可以是无穷大)
