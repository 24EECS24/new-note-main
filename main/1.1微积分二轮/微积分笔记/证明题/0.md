### 分析
要证 $f'(\xi)\sin(2\xi) = -2f(\xi)$。

$$f'(\xi) = \frac{-2f(\xi)}{\sin(2\xi)}$$
$$f'(\xi) + \frac{2}{\sin(2\xi)} f(\xi) = 0$$
$见到\square'+P\square，令g(x)=\square e^{\int P dx}$ 
$$
\begin{align*}
\int \frac{2}{\sin 2x} \, dx 
&= \int \frac{1}{\sin x \cos x} \, dx  \\[4pt]
&= \int \frac{\cos x}{\sin x \cos^2 x} \, dx  \\[4pt]
&= \int \frac{1}{\tan x}\cdot \sec^2 x \, dx  \\[4pt]
&= \int \frac{1}{\tan x} \, d(\tan x)  \\[4pt]
&= \ln(\tan x)
\end{align*}
$$
 $e^{\ln(\tan x)} = \tan x$，
 故辅助函数取 $g(x) = f(x)\tan x$。

### 证明

$$
\begin{align*}
&设 g(x) = f(x)\tan x  \\[4pt]
\because &f(x) 为奇函数，在 \left[-\frac{\pi}{4},\frac{\pi}{4}\right] 上连续， \\[4pt]
&在 \left(-\frac{\pi}{4},\frac{\pi}{4}\right) 上可导， \\[4pt]
\therefore &f\left(-\frac{\pi}{4}\right) = -f\left(\frac{\pi}{4}\right)  \\[4pt]
\because &\tan\left(-\frac{\pi}{4}\right) = -1，\tan\left(\frac{\pi}{4}\right) = 1， \\[4pt]
\therefore &g\left(-\frac{\pi}{4}\right) = f\left(\frac{\pi}{4}\right) = g\left(\frac{\pi}{4}\right)  \\[4pt]
&由罗尔定理可: \\[4pt]
&\exists \xi \in \left(-\frac{\pi}{4},\frac{\pi}{4}\right), \text{使得 } g'(\xi) = 0  \\[4pt]

&\begin{aligned}
g'(\xi) &= f'(\xi)\tan\xi + f(\xi)\sec^2\xi = 0  \\[4pt]
&=f'(\xi)\sin2\xi + 2f(\xi)   \\[4pt]
&= 0  \\[4pt]
\end{aligned} \\[4pt]
&即 \\[4pt]
&f'(\xi)\sin(2\xi) = -2f(\xi)  \\[4pt]

\end{align*}
$$
