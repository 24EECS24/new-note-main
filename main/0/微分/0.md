**题目**

设函数 $y=f^2(\cos x)$，其中 $f$ 可导，则 $y'=$（　　）

- A. $2f(\cos x)$
- B. $2f(\cos x)f'(\cos x)$
- C. $-2\sin x f(\cos x)f'(\cos x)$
- D. $2\sin x f(\cos x)f'(\cos x)$

**答案**：C

**解析**

> 由复合函数链式求导法则，外层为平方、中层为 $f$、内层为 $\cos x$：
>
> $$y'=2f(\cos x)\cdot f'(\cos x)\cdot(\cos x)'=-2\sin x\,f(\cos x)f'(\cos x)$$
>
> 选 C。

**考点**：复合函数链式求导（多层复合）
