
**题目**

设函数 $f(x)$ 的定义域为 $[1,3]$，则函数 $f[\ln(1+x)]$ 的定义域为（　　）


**答案**：$[e-1,\,e^3-1]$

**解析**

> 令 $1\leq\ln(1+x)\leq3$，则 $e\leq1+x\leq e^3$，即 $e-1\leq x\leq e^3-1$。

**考点**：抽象/复合函数求定义域（由外层 $f$ 定义域反求内层 $x$ 的范围）


**另一解法：** 
内层定义域：$1+x>0$，解得$x>-1$。


$$1\leq \ln(1+x) \leq 3$$

$$e \leq 1+x \leq e^3$$
外层定义域：
$$e-1 \leq x \leq e^3 -1$$


取交集，
$$
\begin{align*}
x>-1 \cap [e-1, e^3 -1] = [e-1, e^3 -1]
\end{align*}
$$
