








**另一方法** 
求解二阶常系数齐次线性微分方程：
$$y''+3a y'+2y=0$$
写出对应的特征方程（修正手写漏写的一次项$r$，符合特征方程构造规则）：
$$r^2 + 3a r + 2 = 0$$
对特征方程使用十字相乘法分解：
二次项$r^2$分解为$r \cdot r$，常数项$2$分解为$1 \times 2$，交叉项求和得$r\cdot1 + r\cdot2 = 3r$，对应特征方程的一次项系数$3a$。
$\because e^{-x}$是方程的解，故特征根$\alpha=-1$（即$r=-1$）。
根据特征根对特征方程做分解：特征方程可写为$(r+1)(r+2)=0$，即$(r - (-1))(r - (-2))=0$；以根做十字相乘验证：二次项分解为$r\cdot r$，常数项对应根的相反数项为$(-1)\times(-2)$，交叉项求和得$r\cdot(-1) + r\cdot(-2) = -3r$。
由韦达定理，对特征方程$r^2 + pr + q=0$，两根$r_1,r_2$满足$r_1+r_2=-p$，此处$r_1=-1,r_2=-2$，故$-3a = (-1)+(-2) = -3$。
$$\Rightarrow a=1$$
