## 小结“加深理解”

先说结论：判断反常积分是收敛还是发散，本质上是一个比阶问题。

看$\displaystyle \int_{a}^{+\infty} f(x)dx$是否存在：
关键看$f(x)\to 0$的速度，即：看无穷小的阶数，
无穷小的阶数越高，$f(x)\to 0$的速度越快。

$f(x)$与$x$轴的靠近程度越大，$\displaystyle \int_{a}^{+\infty} f(x)dx$的面积值越易为有限值。

```tikz
\begin{document}
\begin{tikzpicture}[scale=0.9]
\fill[blue!15] (1,0) -- plot[smooth] coordinates {(1,2.4) (2.5,1.4) (4,0.7) (6,0.3) (7.5,0.15)} -- (7.5,0) -- cycle;
\draw[thick,smooth,->] plot coordinates {(1,2.4) (2.5,1.4) (4,0.7) (6,0.3) (7.5,0.15) (8.3,0.08)};
\draw[->] (0.5,0) -- (8.8,0) node[right]{$x$};
\draw[->] (1,-0.4) -- (1,2.9) node[above]{$y$};
\draw (1,0.1)--(1,-0.1) node[below]{$a$};
\node at (8.2,-0.35){$\infty$};
\end{tikzpicture}
\end{document}
```




（对应无穷限反常积分几何意义示意图）

$\displaystyle \int_{a}^{b} f(x)dx$，其中$\lim\limits_{x \to a^+} f(x) = \infty$。
看$\displaystyle \int_{a}^{b} f(x)dx$是否存在：
关键看$f(x)\to\infty$的速度，即：看无穷大的阶数，
无穷大的阶数越低，$f(x)\to\infty$的速度越慢。

$f(x)$与$x=a$这条垂线的靠近程度越大。


```tikz

```
