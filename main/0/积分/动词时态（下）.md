# 一、回顾与摸底：

开场先回顾昨天的两类态：一般态（一般现在、一般过去、一般将来、过去将来）和进行态（现在进行、过去进行、将来进行）。今天讲剩下两类——==完成态、完成进行态==。

## 摸底第一题：先把"靠语感"打回去

The boy ___ hot on the forehead, so he must be sent to hospital at once.

- `feel` 在这里是**感官动词、属于系动词**，后面 `hot` 是形容词作表语，所以它==根本没有被动语态==，先把 be done 的选项干掉。
- 句子没提过去的事，现在完成时也不成立。剩下一般现在和现在进行。
- 现在进行要满足昨天讲的**点、情、瞬**：这个句子没有时间点（now / at present / look / listen），没有频度副词带感情，feel 也不是起止位移的瞬时动词——三条都不沾。


> [!warning] 所以答案是一般现在时 feels
> 她又强调了一遍：高中语法题**不能靠"读起来像"**。初中凭语感能蒙对，高中"法就是规则"，每一步都得有依据。

## 三道完成时思考题：三个"隐含义"先暴露出来

````col
```col-md
**现在完成 → 灯现在是关的**

He **has turned off** the light.

动作发生在过去，但用现在完成时就暗含：那个灯==现在关着==。如果只是陈述过去事实，用一般过去时就够了，不必用完成时。

```

```col-md
**过去完成 → 跟现在没关系**

I realized I **had left** my notebook in the classroom, so I went to fetch it.

过去完成强调==过去的过去==。笔记本已经取回来了，"落笔记本"这件事对现在没有任何影响，所以现在教室里没有它。

```

```col-md
**现在完成进行 → 还可能继续**

I **have been watering** the flower.

多了个进行的 ing，就表示这个动作==有可能还没干完、还要继续==。如果已经浇完了，直接用完成时即可，没必要用进行。

```
````

# 二、完成态：三种形式，重点是"现完 vs 一过"（11:20–30:30）

## 1. 三种完成时的形式

| 时态 | 形式 | 备注 |
| --- | --- | --- |
| 现在完成时 | have / has done | 初中学过 |
| 过去完成时 | had done | 初中口诀"过去的过去" |
| 将来完成时 | ==will have done== | 高中新学，最难 |

## 2. 考点一：现在完成 vs 一般过去——两个字，看"影响"

她讲了自己丢钥匙的故事：在留学生宿舍等人，把钥匙弄丢了，打电话说 `I lost my key`，对方只回"知道了"却不回来；改成 `I have lost my key`，对方立刻懂了——因为==进不去门了==。

````col
```col-md
**I lost my key（一般过去）**

只是陈述一个发生在==过去==的客观事实，侧重点在过去，跟现在不挂钩。对方听到的信息就是"你丢过钥匙"。

```

```col-md
**I have lost my key（现在完成）**

哪怕后半句不说 so I can't enter now，对方也知道：这个动作==对现在有影响==——我现在进不去了。这才是完成时存在的理由。

```
````

### 先用标志词粗判

| 时态 | 标志词的"形状" | 常见词 |
| --- | --- | --- |
| 一般过去 | ==过去的时间点== | yesterday, …ago, last night/year |
| 现在完成 | ==时间段 / 截止到现在== | already, yet, just now, so far, since + 点, for + 段 |

> [!tip] 注意单独一个 since
> 高中常出现 `since` 后面什么都不加，它其实是省略了 then，等于 **since then**，照样用现在完成时（全国卷考过"从那时起我们十年没见"）。

### 再用语境定夺——语境比标志词更硬

- 一般过去：动作只发生在过去，==现在已经不干了==，跟现在无关。
- 现在完成：动作一定跟现在有联系，影响可能明写，也可能是隐含的。

例：
- I **have washed** my hands, so I can help you with the cooking.（影响在后半句：现在能帮忙做饭）
- I **have found** the book you were looking for. Here you are.（影响：书现在就在我手里，才能说"给你"）

## 3. 考点二：固定句式，看到就选完成时

> [!warning] This / It is the + 序数词 / 形容词最高级 + time（that …）
> 后面的从句==只能用现在完成时==，不用分析语境，背下来就得分。
> 例：This is the first time that he **has gone out** with a girl.

变形只改一个地方：

- 前面是 `is` → 从句现在完成；前面换成 `was` → 从句换成==过去完成==。
- 例：That was the first time that he **had gone out** with a girl.

## 小试牛刀（P17–18，三题）

1. — Why don't you join us in the game? — Because I **haven't finished** my homework yet.（有标志词 yet，影响是"现在不能加入"）
2. Patients' medical notes went missing two days ago and nobody **has seen** them since.（since = since then，到现在还没找到）
3. Doctor Wang, who **studied** western medicine for six years in New York, is now working in a hospital in Shanghai.

> [!warning] 第 3 题最容易错：看见 for six years 就选现在完成
> 但后半句明确说他==现在已经在上海工作、不再是学生了==，所以学医这个动作只属于过去，用一般过去。**语境压过标志词**；只要没建立因果关系，"现在在上海工作"就不叫过去动作的影响。
> 她还提醒：新高一最爱选过去完成，因为它是初中最后学的，显得"高端"——这是个毛病，得改。

# 三、过去完成时：过去的过去（30:30–39:00）

初中口诀"过去的过去"没错，但高中要把它变成可操作的条件。

## 1. 想用过去完成，两个条件同时满足

1. 句子里必须体现==过去的过去==：先在时间轴上立一个"过去"的靶子，所用的动作发生在这个靶子之前。
   - 例：When we arrived, the meeting **had ended**.（arrived 是过去，会议结束在它之前）
2. 句子里必须先出现一个==一般过去时（did）==，否则没有过去的参照，无从体现"过去的过去"。

> [!tip] did 是必要条件，不是充分条件
> 句中有 did，不一定就能填过去完成；但没有 did，几乎不可能填过去完成。这就是数学里的"必要不充分"。

## 2. 例外：by + 过去的时间

看到 `by + 过去时间`（如 by the end of last month），==哪怕句中没有 did 也常用过去完成==，因为这个标志词本身就暗含"在过去那个点之前"，即过去的过去。

## 3. 固定句式

`It / That was the … time that …` 从句用过去完成（前面考点二的变形）。

## 4. 心理活动动词：表"本来以为"，时态往前退一步

表示心理活动的动词——think、want、plan、intend、expect、hope、mean 等，当你想说"本来如此、实际却不是"时，时态==整体往前推一格==：

- 现在的想法落空：现在 → 过去。I **thought** you were staying for dinner.（结果你没留）
- 过去的想法落空：过去 → 过去完成。I **had thought** he would stay for dinner.（结果他没待）

讲义上的例子：
- I **had meant** to help you, but I was too busy at that moment.
- I **had hoped** to be back last night, but I didn't catch the train.

> [!info] 这是高二虚拟语气的预告
> 现在听不懂没关系，先知道"表虚假愿望就把心理动词往前推一步"，到高二学虚拟语气会轻松很多。

## 过去完成时三条用法小结

1. 两个条件：过去的过去 + 句中有 did；
2. 固定句式：It was the … time that …；
3. 心理活动动词往前退一步。

# 四、完成进行态：未中断、可持续、带感情（60:00–71:00）

她用"张老师在电影院等我"的场景引出这两个句子：

1. I **have waited** for you for a long time.（现在完成）
2. I **have been waiting** for you for a long time.（现在完成进行）

**形式：have / has been doing。**

相同点：两者都能表示过去动作对现在的影响。区别在下面三条。

| 区别 | 现在完成进行 | 说明 |
| --- | --- | --- |
| ① ==动作从未中断== | 这期间只干这一件事 | waiting 的过程里没去上厕所、买爆米花、跟别人聊天；现在完成时没有这层含义 |
| ② ==动作可持续== | 可能还没干完，要继续做 | 你不来，我就一直等下去；现在完成可能已经结束 |
| ③ ==带感情== | 因为含进行，所以能带情绪 | 只有进行能带感情，这里是"等成望夫石"的执着 |

例：
- 已经给完了：I **have given** him the book.（动作结束，用一般过去 / 现在完成）
- 一直打、还要打：I **have been playing** football for five years.（五年没中断，将来继续）

> [!tip] 考场上怎么选
> 语法填空一般两种都接受；天津卷会区分——强调==现在不干了==用现在完成，强调==还在干==用现在完成进行。如果句子没说还干不干，选**现在完成进行更保险**，因为它涵盖的范围更大（子集关系，选集合大的那个）。

## 小试牛刀（P21，两题）

1. I **have been writing** the report since early morning, but I haven't finished it yet.（还没写完，符合"可持续"）
2. In the last few years, China **has made** great achievements in environmental protection.（既无过去的过去，也无 did，不能选过去完成；make achievements 取得成就）

# 五、完成时总口诀：一张思维导图（71:00 左右）

> [!tip] 完成时三句口诀
> **过去发生已结束，影响至今用现完；**
> **过去发生已结束，影响过去用过完；**
> **过去发生未结束，持续进行现完进。**

- 第一句关键词==影响至今==：有过去动作对现在的影响才用现在完成，没有就一般过去。
- 第二句跟现在无关，用过去完成仍要满足"过去的过去 + did"。
- 第三句还要继续干，用现在完成进行。

# 六、被动语态：先语态，后时态（72:00–80:30）

## 1. 前提：只有及物动词才有被动

主动变被动就是把宾语提到句首作主语、原主语放到 by 后、动词改成 be done。因为要先有宾语才能往前提，所以==只有及物动词能变被动==。

## 2. 考点一：时态和语态结合着考

高中从不单独考被动，一道题里既让你判断主动 / 被动，又让你判断是哪种时态、哪种态。

> [!warning] 做题顺序：先语态，后时态
> 语态只有两个选择（主动 / 被动），读句子就能定；时态有十几个，麻烦得多。所以先把主被动定下来，再去想时态。

### 主动 / 被动对照表（口诀：done 字不许动，be 随 do 时改）

| 时态 | 主动 | 被动 |
| --- | --- | --- |
| 一般现在 | do | am/is/are done |
| 一般过去 | did | was/were done |
| 一般将来 | will do | will be done |
| 过去将来 | would do | would be done |
| 现在进行 | am/is/are doing | am/is/are ==being== done |
| 过去进行 | was/were doing | was/were ==being== done |
| 将来进行 | will be doing | ——（无被动） |
| 现在完成 | have done | have ==been== done |
| 过去完成 | had done | had ==been== done |
| 现在完成进行 | have been doing | ——（无被动） |

> [!warning] 检查被动：be 和 done 缺一不可
> 写 `have done` 不算被动，因为没有 be；写个 be 没有 done 也不算。be 可以是 am/is/are、was/were、will be、being 等各种时态形状，跟着主动 do 的时态走（be 随 do 时改），done 原样不动。
> 她布置的作业：拿昨天那张 16 格表，用一个及物动词（如 paint）把每一格的被动都写一遍，自己就会发现将来进行、现在完成进行根本写不出被动。

# 七、主动表被动：感性状值（81:00–88:00）

"反着用"的第一种：明明是主动形式，却表示被动含义。讲义上归成四类，口诀==感性状值==。

1. **感——感官动词**：look / sound / smell / taste / feel 后面加形容词作表语，不用被动。
2. **性——表性质、性能**：物作主语，后面加副词修饰。如 The books **sell well**；The cloth **washes well**；The door **opens** well。
3. **状——表状态**：have、last、exist、consist of 等，描述的是状态而非动作。
4. **值——值得被做**：==be worth doing==（不能说 be worth to do）；deserve doing / to be done。例：The book is worth **reading**.

> [!info] 被动表主动先不讲
> "用被动形式表主动含义"要留到**非谓语动词**部分，现在讲了会和 ing / ed 形容词混淆，所以这讲只掌握主动表被动。

# 八、不能用被动：不态属（103:00–110:00）

"反着用"的另一面：有些词压根不能用被动，口诀==不态属==。

| 类别 | 含义 | 例词 / 例句 |
| --- | --- | --- |
| ① ==不==及物 | 后面没有宾语，无法变被动 | take place, happen, come true, break out, run out |
| ② ==态==（状态） | 主动形式本身就含被动意思 | consist of, suffer from, recover from, last |
| ③ ==属==（归属） | 含义里自带"被拥有" | have, contain, belong to |

几个对比要点：

- "由……组成"三个说法：make up、compose 都有被动（be made up of / be composed of），唯独 ==consist of 没有被动==。
- `suffer from`（遭受）、`recover from`（从……恢复）自带被动含义，只要出现 be suffered / be recovered 就判错。
- `belong to`（属于）：这本书属于我 = 这本书被我拥有，含义里已有被动，不用再变。
- 判断及物不及物最直接的办法：看它后面有没有宾语。
