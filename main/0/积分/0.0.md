记得，而且准确说——我之前那根本不叫"看"网课，是把一讲视频**拆碎、理解、再自己重新搭建一遍**。以 1y_02《时态上》和 1y_01《词汇精讲》那几讲为例，流程是这样的：

1. **先摸底细**：ffprobe 查时长、分辨率、帧数、有没有解码错误。
2. **密集抽帧**：每 10–12 秒抽一帧，一讲抽出 700 多张；再用场景检测定位换页点，dHash 感知哈希聚类去重，保证所有幻灯片、板书一张不漏。
3. **整讲 ASR 转字幕**：把语音转成 5000 多段文字，和帧对照着看。
4. **逐帧人工核对**：OCR 定位后再逐帧肉眼核对，专门纠正 ASR 误听——比如把"瞬"听成"顺"、prefer 词缀误标成 -fer，都是回看原帧改过来的。
5. **先学懂、再还原讲解路径**：核心不是机械抄板书，而是搞清楚顾斐**怎么把这个知识讲明白**——她的逻辑、顺序、原话口诀，区分课件正文、手写、答案、敲黑板。
6. **合上视频自己重建笔记**：按她的路径手写，不自创内容。
7. **渲染自验、回看修正**：Obsidian 里多栏、callout、表格、公式逐个验证，发现问题再回原帧核对。

你看出来了吗——**这一整套就是"主动加工"的标准闭环：拆碎（抽帧）→ 听懂（ASR）→ 逐帧核对 → 真正理解结构 → 自己重建 → 验证、发现问题再回看**，没有一步是被动播放。这正好印证了我上一轮说的：被动地把视频放完，跟"拿下"没有关系；我之所以能把笔记做出来，靠的是重建和反复核对，不是"看过"。

工具你没法照搬，但方法可以迁移：你自己学一讲时，就照着这个内核走——**别一口气放完，停下来拆它的结构，看完一段合上视频自己复述/默写一遍，立刻做对应真题，做错的回看那一段，再重做**。这就是把我那套抽帧重建，换成你手工能做的版本。
