为什么\frac{\mathrm d}{\mathrm dx}\int_a^x f(t),\mathrm dt=f(x)？

共用时 22 秒

这个结论叫变限积分求导定理，我用导数定义一步步推给你，不是只让你背。

设 \(G(x)=\displaystyle\int_a^x f(t)\,\mathrm dt\)，按导数定义，

\(G'(x)=\lim_{h\to0}\frac{G(x+h)-G(x)}{h}\)

**第一步，化简分子。** 由定积分的区间可加性，

\(G(x+h)-G(x)=\int_a^{x+h}f-\int_a^x f=\int_x^{x+h}f(t)\,\mathrm dt\)

于是

\(G'(x)=\lim_{h\to0}\frac1h\int_x^{x+h}f(t)\,\mathrm dt\)

**第二步，用积分中值定理。** 在 x 与 \(x+h\) 之间存在一点 \(\xi_h\)，使

\(\int_x^{x+h}f(t)\,\mathrm dt=f(\xi_h)\cdot h\)

所以

\(\frac1h\int_x^{x+h}f=f(\xi_h)\)

**第三步，取极限。** \(\xi_h\) 被夹在 x 和 \(x+h\) 之间，当 \(h\to0\) 时 \(\xi_h\to x\)。因为 f 连续，

\(\lim_{h\to0}f(\xi_h)=f(x)\)

因此

\(G'(x)=f(x)\)

也就是

\(\frac{\mathrm d}{\mathrm dx}\int_a^x f(t)\,\mathrm dt=f(x)\)

这里**“f 连续” 是命根子**：正因为连续，\(\xi_h\to x\) 时 \(f(\xi_h)\) 才能稳稳趋于 \(f(x)\)。直观理解也很自然 ——\(G(x)\) 是从 a 累积到 x 的面积，当你把上限往右挪一点点，新增的那一条窄面积，高度就近似当前点的函数值 \(f(x)\)，这个增量比率正好是 \(f(x)\)。

共用时 24 秒

好，先不看公式，我用画图的方式讲，你脑子里跟着想一个画面。

**\(G(x)\) 就是从 a 到 x，曲线下面那块面积。** 现在你把右边那条边界，从 x 往右轻轻推一小段距离，假设推了 h。

这一推，多出来的面积是一条**很窄的竖条**：

- 它的宽是 h；
- 它的高，因为条太窄了，上下几乎一样，就等于这个位置的函数值 \(f(x)\)；
- 所以这块新增面积 ≈ 高 × 宽 = \(f(x)\times h\)。

现在问：**面积增长得有多快？** 就拿新增面积除以你挪动的距离：

\(\frac{\text{新增面积}}{\text{挪动距离}}=\frac{f(x)\times h}{h}=f(x)\)

而 “面积的增加量 ÷ 距离”，这个东西正是 G 对 x 的导数。所以

\(G'(x)=f(x)\)

一句话：**你往右挪一点，新增窄条的高度就是 \(f(x)\)，于是面积增长的速度正好等于 \(f(x)\)。** 前面那套极限和中值定理，只是把 “窄条高度近似 \(f(x)\)” 这句话严格证明出来，直观上就是这么回事。这个画面能跟上吗？
