证明不等式：$\ln(1+e^x)-x>\dfrac{1}{e^x+1}$，$x\in(-\infty,+\infty)$。
?

`````col
````col-md

===



$$
\begin{align*}
证明：& \\[4pt]
&\ln(1+e^x) - \ln e^x > \frac{1}{e^x + 1}  \\[4pt]
&\ln(1+e^{-x}) > \frac{1}{e^x + 1}  \\[4pt]
&设e^x=t， \\[4pt]
&\ln\left(1+\frac{1}{t}\right) > \frac{1}{t+1}  \\[4pt]
&g(t) = \ln\left(1+\frac{1}{t}\right) - \frac{1}{t+1}  \\[4pt]
&\begin{aligned}
g'(t) &= \frac{1}{1+\frac{1}{t}} \cdot \left(-\frac{1}{t^2}\right) + \frac{1}{(t+1)^2} \\[6pt]
&= \frac{-\frac{1}{t^2}}{1+\frac{1}{t}} + \frac{1}{(t+1)^2} \\[6pt]
&= \frac{-\frac{1}{t}}{t+1} + \frac{1}{(t+1)^2} \\[6pt]
&= \frac{-\left(1+\frac{1}{t}\right) + 1}{(t+1)^2}
\end{aligned} \\[4pt]

&\because \ -\left(1+\frac{1}{t}\right)+1 = -\frac{1}{t} < 0，(t+1)^2 > 0， \\[4pt]
&\therefore \ g'(t) < 0 \\[4pt]
&\because \ \lim_{t \to +\infty} g(t) = 0 \\[4pt]
&\therefore \ x\in(-\infty,+\infty)，\ln(1+e^x) - x > \frac{1}{e^x + 1}   \\[4pt]

\end{align*}
$$

**不设t也照样做** 
设$f(x)=\ln(1+e^x)-\ln e^x - \dfrac{1}{e^x+1}$
$$
\begin{align*}
f'(x) &= \frac{e^x}{1+e^x} - \frac{e^x}{e^x} + \frac{e^x}{(e^x+1)^2}\\[4pt]
&= \frac{e^x}{1+e^x} - 1 + \frac{e^x}{(e^x+1)^2}\\[4pt]
&= \frac{-1}{e^x+1} + \frac{e^x}{(e^x+1)^2}\\[4pt]
&= \frac{-(e^x+1)+e^x}{(e^x+1)^2}\\[4pt]
&= \frac{-1}{(e^x+1)^2}\\[12pt]
\because\ &(e^x+1)^2 > 0\\[4pt]
\therefore\ &f'(x) < 0，\text{即}f(x)\text{在定义域内单调递减}\\[12pt]
\because\ &\lim_{x \to +\infty} f(x) = \lim_{x \to +\infty} \left( \ln\frac{1+e^x}{e^x} - \frac{1}{e^x+1} \right)\\[4pt]
&\text{（}x\to+\infty\text{时，}\frac{1+e^x}{e^x}\to 1\text{）}\\[4pt]
\therefore\ &\lim_{x \to +\infty} f(x) =  \lim_{x \to +\infty} \left( \frac{1}{e^x} - \frac{1}{e^x+1} \right)\\[4pt]
&= 0 - 0\\[4pt]
&= 0
\end{align*}
$$
`````
