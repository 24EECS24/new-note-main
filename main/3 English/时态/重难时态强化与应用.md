> 这是 2022 秋高二 S 班第 8 讲，是高二年级第一次系统复习时态语态。她不再按"时间"分，而是按"态"重新整理，并把一个动词的三个考点——==时态、语态、主谓一致（时、语、数）==——放在一起讲。这讲的重头是**主谓一致**和**倒装句里的单复数**，这两块前面讲次没有展开。




# 一、解题总流程：先语态，后时态，最后主谓一致

> [!tip] 三步顺序
> ① 先判断主被动（语态）；② 再判断时态（一个中心两个基本点：语境 + 标志词 / 固定句式）；③ 最后确定单复数（主谓一致）。
> 出错往往是因为刚想清时态就忘了被动，或刚想清被动又忘了进行——三个考点要同时拿住。

# 二、语态：be + done

## 1. 会写每种时态的被动

被动 = be + done，done 不变，be 随时态变。按 4×4 十六格，每格都要会写被动；最容易错的是进行态和完成态的被动：

| 时态 | 被动形式 |
| --- | --- |
| 现在进行 | am/is/are being done |
| 过去进行 | was/were being done |
| 现在完成 | have/has been done |
| 过去完成 | had been done |
| 一般将来 | will be done |
| 过去将来 | would be done |

进行态的被动里 ==being 不能丢==；将来进行时没有被动。

## 2. 没有被动：不态属性

- 不——不及物动词（发生类 take place/happen、位移类、胜负生死类）和系动词。
- 态——表状态：belong to、consist of、suffer from。
- 属——归属：have、own、contain。
- 性——物作主语 + 副词表属性，主动表被动：The pen writes smoothly；The wet wood doesn't catch fire easily。
- 特殊：need/want/require + doing = to be done；be worth 只能加 doing。

## 3. 易错词 operate

- 表"运行、操作"时是不及物动词，和 run 一样，没有被动：The hospital operates well.
- 表"做手术"时要加介词 on：operate on sb；被动 be operated on，==介词 on 不能丢==（同理 a baby to be looked after 的 after）。

# 三、时态：按"态"整理

## 1. 一般态：习惯、事实、主将从现、时间表

- 习惯：习惯性动作，配频度副词 every day / often / usually / sometimes。
- 事实：客观事实、真理永一现。
- 主将从现：主句将来时，从句用现在时表将来；高中补充主情从现、主祈从现。
- ==时间表==：按时刻表、计划即将发生的事，用一般现在时表将来（火车出发、飞机起飞、学校排课）。

标志词：一般现在 on Fridays / every…；一般过去 yesterday / last…；一般将来 next… / tomorrow / in the years ahead。

## 2. 进行态：点情瞬

- 点——时间点：now / at present / at the moment（现在）；then / …o'clock yesterday（过去）；this time tomorrow（将来）。
- 情——配频度副词（always / usually）表强烈感情：Why are you always coming so late?
- 瞬——起止、位移类瞬时动词（go / come / leave / start）用进行表将来：Mary is leaving on Friday.

## 3. 完成态：两两 PK

- 现完 vs 一过：
  - 看标志词：段状时间 for + 时间段（==不保险==，近年多次出现 for 却不用现完）、since + 过去点、up to now、so far。
  - 看语境：强调"过去动作对现在的影响、现在还做"用现完；强调"现在已经不做"用一般过去。
  - 典型：爷爷在银行工作十年、现在被聘为大学教授——现在不做了，用一般过去，哪怕有 for ten years。
- 过完：触发条件苛刻，==过去的过去 + did 缺一不可==；例外是 by + 过去时间（隐含过去的过去）。
- 将来完成：will have done，配 by + 将来时间，高考基本不考。

## 4. 完成进行态

have/has been doing，和现完几乎通用，只多一层"还没做完、要继续"；没有被动。

# 四、主谓一致：本讲重点

## 1. 必单 / 必复

- 必单：时间、距离、金钱作整体（five dollars / five hours / one hundred meters）；不定代词（everybody / something）；主语前有 no / each / every；动名词、不定式作主语。
- 必复：集体名词强调个体（family members）；the + 形容词表一类人（the rich / the poor / the young）。
- 集体名词（army / class / team / family / couple）：强调整体用单，强调个体用复。

## 2. 就近 / 就远

- 就近：not only…but also、either…or、neither…nor、there be、or——谁离谓语近谁说了算。疑问句里谓语在前面，就看前面离得近的主语。
- 就远：with / together with / along with / as well as / besides / rather than / except——把它们当介词短语，去掉后找真正主语，看前面那个。
  - Mr Smith together with his family members… 谓语用单数，主语是 Mr Smith。

## 3. 倒装句：真正的主语在后面

> [!warning] 地点 / 时间状语置句首的完全倒装
> 结构是"状语 + 谓语 + 真正主语"。不要被前面的名词带偏，单复数要看==后面的真正主语==。
> 例：Far more pressure is associated with high-standard jobs. 真正主语是 pressure（单数），不是前面的 jobs。
> 例：In 1812 there were 66 novels published. 真正主语是 66 novels（复数），用 were published。

## 4. 数量短语：看限定词，不看后面的名词

- 百分 / 分数（…percent of、one fifth of）：看后面名词，名单用单、名复用复。
- kind / sort / series / amount + of：==看限定词本身的单复数，不看名词==。
  - a kind of… 用单；kinds of… 用复。
  - a series of group activities is scheduled.
  - a large amount of… 用单；large amounts of… 用复（哪怕修饰不可数名词 water，Large amounts of water are… 仍用复数）。
- quantity 最麻烦：quantities of 一律用复；a quantity of 看后面名词，单 / 不可数用单、复用复。

## 5. 三组快板口诀（按她原话记）

- 第一组：集体名词不一般，army class team family couple 最常见；强调个体要用复，强调整体要用单；时间距离与货币，谓语多单复少见；百分分数作主语，名词决定为负担。
- 第二组：and 连接两主语，单复有意灵活变；many a / more than one 谓语应用单；a boy or two 谓用单，one or two boys 谓用复；there be / not only…but also / either…or / neither…nor 就近原则挂嘴边；连接两主语谓语看前定负担（就远）。
- 第三组：不定代词作主语谓语一律用单数；主语单数后接介词，谓语单复与介词无关；the + 形容词表一类；amount / quantity 加 of 谓语单复看其本身；no / each / every 相连谓语必用单。

and 连接的两个名词若共用一个冠词，指同一个人或一整套：a singer and dancer（一个歌手兼舞者，单）；a fork and knife（一套刀叉，单）。

# 五、阅读：never too old to start

这讲阅读是一项追踪约二十年的锻炼研究，主旨是"什么时候开始锻炼都不晚"。

- 标题题选 ==Never too old to start==：不管二十几岁还是四五十岁开始，只要锻炼就有好处。
- 推断题避开"所见即所得"的选项，要同义替换；主旨题警惕以偏概全和主题扩大。
- 生词：fade（逐渐衰退）、take sth into account = take sth into consideration（考虑）、carry out（执行；事物作主语用被动，be carried out）。

# 六、这讲的自检要点

- 一个动词同时考时、语、数，三步顺序不能乱：先语态、后时态、最后单复数。
- 进行态被动的 being、被动里的介词（on / after）都不能丢。
- 现完 vs 一过，看到 for 不要急着选现完，先确认"现在还做不做"。
- 倒装句往后找真正主语；kind / amount / quantity 看限定词本身，不看后面名词。
- 主谓一致高考很少单独考，多半并在时态语态那道题里，把三个考点一起想清楚即可。
