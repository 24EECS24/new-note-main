# 一、先分流：这个空到底填谓语还是非谓语

考场上没人告诉你考点，先数句子。

> [!tip] 核心公式
> **一个简单句有且只有一个谓语；谓语个数 = 连接词个数 + 1 = 句子个数。**
> 连接词（that/which/when/if…，有时会省略，先在心里补上）连接句子，出现一个就多一个句子、多一个谓语。

- 数出该有的谓语数，再数句中已有的谓语：**缺谓语 → 走谓语；不缺 → 走非谓语。**
- 注意陷阱：and 若只连接并列成分（day and night），不是连接句子，不计入连接词。

# 二、谓语三件套：时、语、数（先语态 → 后时态 → 最后单复数）

她的固定顺序，理由是语态只有主/被动两种、读句子就能定，时态有 16 种、放后面。

## 1. 先语态（做还是被做）

只有及物动词能变被动（得先有宾语才能往句首提）。

> [!warning] 被动两件套：be + done
> **done 字不许动，be 随时态改。** 有 be 有 done 才叫被动，少一个都不算。
> 进行被动里 ==being== 不能丢（is being done）；将来进行、现在完成进行写不出被动，是正常的。

> [!tip] 主动表被动：感性状值
> **感**——感官动词（look/sound/smell/taste/feel）后接表语；
> **性**——表性能：物作主语 + 副词，The book sells well、The cloth washes well；
> **状**——表状态：weigh/measure + 数字（重达、深达）；
> **值**——值得被做：be worth doing（不能 to do）；need/want/require + doing = to be done。

> [!tip] 压根没被动：不态属性（短版「不态属」）
> **不**——不及物动词和短语（take place、happen、break out、run out）；
> **态**——表状态（last、exist、consist of）；
> **属**——归属拥有（have、own、contain、belong to）；
> **性**——表性质：物作主语 + 副词，主动表被动。

> [!warning] 系动词无被动：壮观似花痴
> **状**——状态 be；**观**——感官；**似**——似乎 appear/seem；**化**——变化 turn/become/go；**痴（持）**——持续 keep/stay/remain。

两个易错细节：

- 被动里的介词不能丢：operate on sb → be operated **on**；look after → be looked **after**。
- 易混四词：rise/arise 不及物无被动，raise/arouse 及物有被动。
- 还有个特殊的 will：The toilet won't flush、The ink won't come out，这里 will 不表将来，是情态动词、表倾向（"就是不……"）。

## 2. 后时态：一个中心两个基本点

> [!tip] 一个中心两个基本点
> **一个中心：以语境为中心；两个基本点：时间标志词、固定句式。**
> 她的底层态度：==标志词只能提示，语境才定答案==。初中那种"看到标志词直接选"的直线思考，高中专门在原地挖坑（"坑里有水，水里有钉"）。

骨架先立住：**4 时 × 4 态 = 16，主考 11 种。** 不会写的形式不用死记，把会的部件拼起来——现在完成进行 = 完成（have）+ 进行（be doing）= have been doing。

| 时 ＼ 态 | 一般 | 进行 | 完成 | 完成进行 |
| --- | --- | --- | --- | --- |
| 现在 | do/does | am/is/are doing | have/has done | have/has been doing |
| 过去 | did | was/were doing | had done | had been doing |
| 将来 | will do | will be doing | will have done | will have been doing |
| 过去将来 | would do | would be doing | would have done | would have been doing |

按"态"记，每条都有口诀：

**一般态——习惯性、事实性、真理性**

- 习惯：动作反复发生，配频度副词；事实：陈述客观事实。
- ==真理永一现==：从句说客观真理，不管主句什么时态，永远用一般现在（He said the earth goes around the sun，不写 went）。
- 主将从现，高中升级为**主情从现、主祈从现**；"从现"只有一般现在/现在完成，没有现在进行。
- 两个易混口诀分清楚：**主过从过将（宾语从句，高一）vs 主过将从过（状语从句，高二虚拟）**；宾语从句另记==主过从必过==（真理除外）。

**进行态——点情瞬（满足任一条即可）**

- **点**——只接时间点（now/at present/this time tomorrow）；
- **情**——带强烈感情，配频度副词，16 时态里只有进行时能带感情（Why are you always coming so late?）；
- **瞬**——起止、位移类瞬时动词（go/come/leave/start/fly/die）用进行表将来。

**完成态——两两 PK，核心看"影响"**

- 现完 vs 一过：==看影响==。现完表过去动作对现在有影响、配段状时间；一过与现在无关、配点状时间。for + 时间段**不保险**，"现在已经不干了"就用一过，哪怕有 for ten years。
- 过完两条件（必要不充分）：**过去的过去 + 句中有 did**，缺一不可；例外是 by + 过去时间。
- ==by 三完成==：by + 过去 → 过完 had done；by now → 现完 have done；by + 将来 → 将来完成 will have done。
- 现完进（have been doing）比现完多三层：**未完成、可持续、带感情**；强调"还没干完、要继续"才用它。

> [!tip] 固定句式（看到就直接套）
> - It is/was the + 序数词/最高级 + time that：is 配现完、was 配过完。
> - Hardly had sb done when sb did；No sooner had sb done than sb did——前半截倒装用过完，后半截一般过去。
> - be doing…when：when 译"突然"，从句固定一般过去。
> - 心理动词**退一步**表"本来……"：had intended/planned/thought（本来打算/以为，实际没成）。

## 3. 最后单复数：主谓一致

找准主语，再看特殊情况。

- **必单**：时间/距离/货币作整体（five dollars、three hours）；复合不定代词；主语被 no/each/every 修饰；动名词/不定式/从句作主语；many a、more than one。
- **必复**：集体名词强调个体（family 指"家人"）；people、police；the + 形容词表一类人（the rich、the wounded）；a number of + 复数。
- 集体名词（family/team/class/army）：整体用单、个体用复。
- **就近**：not only…but also、either…or、neither…nor、there be——谁离谓语近谁说了算。
- **就前（就远）**：with/together with/along with/as well as/besides/except/rather than——当介词短语去掉，看前面真正主语。
- 倒装句：真正主语在后面，别被句首名词带偏。
- 数量短语：分数/百分看后面名词；kind/sort/amount 看限定词本身（a kind 单、kinds 复；Large amounts of water are…仍用复）。
- 两个高频辨析：the number of（单）vs a number of（复）；one of + 复数（从句用复）vs the only one of（从句用单）。
- and 连接看冠词：一个冠词指一人（a singer and dancer，单）；两个冠词指两人（a singer and a dancer，复）。

# 三、非谓语：句子不缺谓语时穿的"马甲"

三类 to do / doing / done，先主被动、后先后；否定 not 一律加最前。

|  | 之前（先于主句） | 同时 | 之后（晚于主句） |
| --- | --- | --- | --- |
| 主动 | having done；to have done | doing；to be doing | to do |
| 被动 | having been done；to have been done；done | being done | to be done |

- **to 分清**：表目的/结果是不定式符号（to do）；表方向/对象是介词（get used to、lead to、stick to、devote to，后接 doing）。
- 过去分词三用法：**被动、完成、状态**，符合一个即可；表状态最容易漏（be seated/lost/stuck/married/located）。
- having done / having been done：用于有明显时间先后、或直接因果（doing 体现不了先后、done 又丢了主动）。
- 逻辑主语通常 = 句子主语；**独立主格 / with 复合结构**是逻辑主语不一致的唯一例外（"独立主语 + 非谓语"）。
- only to do 表出乎意料的结果；感官/使役动词主动省 to（see sb do）、被动把 to 还回来（be seen to do）。
- 写作里的"无头鬼"：合并同主语句子，现在分词作状语——Knowing that…、Faced with…、…, making it hard to…。

# 四、虚拟语气：事情是假的，时态就退一步

> [!tip] 五类触发
> 1. 非真实 if：**主过将从过、主过将完从过完**；be 动词一律 were、无 was。
> 2. 含蓄条件：with/without/but for/otherwise（含蓄选过将完 would have done；表现在/将来选过将 would do）。
> 3. **I drop caps**：Insist/Demand/Require/Recommend/Order/Propose/Command/Advise/Prefer/Suggest 后的从句用 (should) do——should 可省、动词原形不能省；主宾表同都一样。一头一尾特殊：insist、suggest 内容为真不虚拟，为假才虚拟。
> 4. **退一步**：wish/would rather/as if——对现在用过去、对过去用过完、对将来用 would do（would rather 没有 would do 格）。
> 5. It is (high/about) time that sb did / should do。

另两个特殊结构：but 半真半假（but 后是真的不虚拟）；错综时间一分为二（主、从句按各自时间判断）；if 省略用倒装（Were I you…）。

# 五、情态动词：动词原形前的虚词

- 无人称和数的变化，只接动词原形。
- 表推测（可能性递减）：must（一定）> should/ought to（八成）> can/may/could/might（可能）；mustn't 是禁止，"一定不"用 can't。
- 对过去推测：must have done（一定做了）、could/might have done（可能做了）。
- 注意分清：**must have done 是推测、不是虚拟**；真正的情态虚拟是 should/could/might/needn't have done（本应/本可/本不必）。

# 六、黑话速记（一页回忆）

- 分流：**谓语个数 = 连接词个数 + 1**；缺谓语走谓语，不缺走非谓语。
- 谓语顺序：**先语态 → 后时态 → 最后单复数**。
- 被动：**be + done，done 不动 be 变**；主动表被动「**感性状值**」；无被动「**不态属性**」；系动词「**壮观似花痴**」。
- 时态总纲：**一个中心（语境）两个基本点（标志词、固定句式）**；标志词只提示、语境定答案。
- 一般态：**习惯、事实、真理永一现**；主将从现（主情/主祈从现）。
- 进行态：**点情瞬**；只有进行能带感情。
- 完成态：**看影响**；过完 = 过去的过去 + did；**by 三完成**；现完进 = 未完成、可持续、带感情。
- 主谓一致：就近 vs 就前；the number of 单 / a number of 复；one of 复 / the only one 单。
- 非谓语：过去分词**被动、完成、状态**；独立主格/with 是例外；写作"无头鬼"。
- 虚拟：if **主过将从过 / 主过将完从过完**；**I drop caps**；wish 类**退一步**；high time 用 did/should do。
