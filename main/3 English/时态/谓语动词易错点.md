# 一、谓语动词三大考点：时、语、数

> [!tip] 总纲
> 谓语动词就考三件事：**时**（时态）、**语**（语态）、**数**（主谓一致，即单复数）。
> 做任何一道动词题，都要把这三样过一遍，缺一不可。

一个简单句==有且只有一个谓语动词==。已经有谓语了，再出现的动词只能改成非谓语；如果有连接词连接两个句子，就该有两个谓语。

# 二、语态：先语态，后时态

## 1. 为什么先语态

语态只有主动 / 被动两种，读句子就能判断；时态有 16 种。所以先定"做还是被做"，再定时态。

## 2. 被动两件套：be + done

> [!warning] 有 be 有 done 才叫被动
> 缺一个都不算。done 不能改，be 随对应时态变化。
> 例：过去进行时的被动 = was/were + being done。
> 不是每种时态都有被动，写不出来的（如将来进行、现在完成进行）是正常的。

## 3. 没有被动语态：不态属性

> [!warning] 四字口诀：不态属性
> **不**——不及物动词和短语：take place, break out, happen
> **态**——表状态：last（持续）, exist（存在）, consist of
> **属**——归属类：have, belong to, own, contain
> **性**——表性质：物作主语 + 副词，主动形式表被动含义

"性质"的判断标准：及物动词前面是物、后面接副词，此时当不及物用。
- This book **sells** well.
- This pair of shoes **wears** comfortably.
- This brand of knife **cuts** well.

## 4. 非谓语里的主动表被动（先记，后面讲）

- need / want / require + doing 或 to be done（需要被做）：My watch needs repairing = needs to be repaired.
- be worth doing（值得被做，==不能== to be done）：The film is worth watching again.

# 三、时态：一个中心，两个基本点

## 1. 总原则

> [!tip] 一个中心两个基本点
> **一个中心**：以==语境==为中心。
> **两个基本点**：时间标志词、固定句式（有固定句式优先按句式）。

## 2. 一般态：事实性、习惯性、主将从现

- 事实性：陈述客观事实，发生在什么时间就用什么时态。
- 习惯性：反复出现的动作，用一般态。
- 主将从现：时间 / 条件 / 让步状语从句，主句将来、从句现在表将来；高中拓展主情从现、主祈从现。
- 标志词：一般现在多为频度副词；一般过去注意 the other day（不久前的一天）、then。

## 3. 进行态：点情瞬

- 点（时间点）：This time tomorrow I will be using it.
- 情（带感情，配频度副词）：Why are you always coming so late?
- 瞬（起止、位移瞬时动词，进行表将来）：start, open, end, go, come, fly, arrive, take off, die…

## 4. 完成态：两两 PK

**现完 vs 一过**：for + 一段时间==不准==，不能直接判定现完。
- 现完：动作与现在有关、持续到现在，配时间段。
- 一过：==现在已不做==，与现在无关。
- 例：He worked in the bank for ten years, but now he is a professor.（work 现在已不干 → 一过）

**现完 vs 过完**：
- 过完触发条件（且的关系）：① 有过去的过去；② 句中有 did，且动作发生在 did 之前。
- 例外：by + 过去时间自带"过去的过去"，不用再找 did。

**现完进（have been doing）**：比现完多三层——未完成、可持续（未中断）、带感情。全国卷考得少，天津卷偶见，无被动。

## 5. 固定句式

- by + 时间：过去 → 过完（had done）；by now → 现完（have done）；将来 → 将来完成（will have done）。
- This/It is the first time + that 从句（is 配现完，was 配过完）。

# 四、主谓一致：三大快板口诀

## 第一组（考频最高）

> [!tip] 集体名词不一般
> 集体名词不一般，army/team/family/couple 最常见；
> 强调个体要用复，强调整体要用单；
> 时间距离与货币，谓语多单复少见；
> 百分分数作主语，名词决定谓负担。

- family 强调成员 → 复数；强调整体 → 单数。
- five minutes / ten kilometers / five dollars 都按单数。
- 分数 / 百分数：one fifth of the water（water 决定单数）；one fifth of the students（students 决定复数）。

## 第二组

> [!tip] and 连接灵活变
> and 连接两主语，单复有意灵活变；
> many a / more than one，谓语动词应用单；
> a boy or two 谓用单，one or two boys 谓用复；
> 就近原则挂嘴边，with/together with 看前定负担。

- the singer and dancer（一个冠词 = 一人，单数）；the singer and the dancer（两人，复数）。
- the fork and knife（一副刀叉，整体，单数）。
- many a / more than one 虽意为"不止一个"，谓语用单数。
- 就近：there be, here be, not only…but also, neither…nor, either…or（谁近谁说了算）。
- 就远：with, together with, along with, like, such as, rather than, including, besides, except（后面是修饰成分，看前面真正的主语）。

## 第三组（几乎不考，只记一条）

> [!warning] 不定代词作主语，谓语一律用单数
> something, nothing, everything, somebody, nobody, everybody… 一律单数。
> 从句作主语一般也按单数；定语从句的主谓一致看先行词。

# 五、情态动词

## 1. 基本特征

- 没有人称和数的变化，只加动词原形。
- can do（主动）；can be done（被动，be 是原形）。

## 2. 考点一：表推测（可能性从高到低）

| 情态动词 | 含义 | 可能性 |
| --- | --- | --- |
| must | 一定 | 约 100% |
| should / ought to | 应该 / 八成 | 约 80% |
| can / may / could / might | 可能 | 约 50%，四者划等号 |
| may not | 可能不 | 留有余地 |
| can not | 不可能 | 绝不 |

四个注意：
- mustn't 表==禁止==，不表推测；"一定不"用 can't。
- can 一般不用于肯定句；用于肯定句时译"有时可能"（理论上的可能性，常配 sometimes）。
- may / might 一般不用于疑问句（May I… 是委婉语气，不是推测）。
- should 常用于购物场景：Your photos should be ready by five o'clock.

## 3. 对过去的推测（高频）

> [!tip] 情态 + have done
> 过去一定做了：must have done（You must have stayed up late last night.）
> 过去可能做了：could / might have done
> 注意 should have done 不是推测，是虚拟（本来该做却没做）。

## 4. 考点二：基本用法

can 表能力、should 表应该、must 表必须，属中考考点，高考少见。

## 5. 考点三：特殊用法

- must 用于疑问句 / if 条件句，译"非得、非要"：Must you smoke here? If you must, find a smoking section.
- should 表"竟然"（出乎意料）：The killer should be him.
- shall 按法律 / 规则 / 条文：题中出现 law, rule, regulation 时用 shall；二三人称还可表允诺或威胁（You shall be taken to Disneyland if you behave.）。
- may 用于句首表祝愿：May you succeed.
- will / would 表习惯：will 现在 / 将来的习惯，would 过去的习惯。

> [!info] 为什么 used to / had better / would rather 都加动词原形
> 它们本质上都是情态动词，不是什么"固定句型"：
> used to do, had better (not) do, would rather do A than do B。
> 她借此强调：学语法要知其所以然，规则是工具不是束缚。

# 六、五大易错点

1. 先判断要不要填谓语：一个简单句只有一个谓语，已有谓语就填非谓语。谓语常出现在"人、情、be、系"之后。
2. 时态：一个中心两个基本点，语境优先，标志词只作参考。
3. 语态：先语态后时态，记住无被动的"不态属性"。
4. 情态动词接序错误：情态动词后必须是动词原形。
5. 动词形式写错：规则 / 不规则变化要熟，重点练 lie、refer、fall 等常考变形。
