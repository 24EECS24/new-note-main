# 一、动词考点全景

动词在句中要么作谓语、要么作不了谓语，共五个考点：

- 作谓语：时态、语态、主谓一致（时、语、数），以及虚拟语气。
- 作不了谓语：非谓语动词（to do / doing / done）。
- 情态动词也是动词的一个小分支。
- 虚拟语气通过==动词时态退一步==来体现：事情是假的、或还没发生，就用退一步的时态。

本讲主攻三大类四小分支：时态语态、主谓一致、非谓语、虚拟语气。

# 二、谓语动词：三步流程

> [!tip] 先语态 → 后时态 → 最后主谓一致
> ① 判断主被动；② 判断时态（一个中心两个基本点：语境 + 标志词 / 固定句式）；③ 判断单复数。

# 三、时态：按"态"整理

## 1. 一般态：三性

- 习惯性：配频度副词 usually / often / sometimes。
- 事实性：客观事实、真理永一现。
- 特殊用法：主将从现（含主情从现、主祈从现）、时间表。

## 2. 进行态：点情瞬

- 点——时间点：now / at present（现在）；…o'clock yesterday / then（过去）；this time tomorrow（将来）。
- 情——配频度副词表强烈感情：Why are you always coming so late?
- 瞬——起止、位移类瞬时动词（go / come / fly / arrive / take off / start）用进行表将来。

## 3. 完成态：两两 PK

- 现完 vs 一过：段状时间 vs 点状时间；for 是例外（for + 时间段不一定用现完）。"过去这么干、现在不干了"用一般过去，哪怕有 for five years。
- 过完 vs 现完：过完触发条件苛刻，==过去的过去 + did 缺一不可==，例外是 by + 过去时间。

## 4. 固定句式

- It is the + 序数词 + time that sb have/has done（is 换 was 则用 had done）。
- 一……就……：Hardly had sb done when sb did；No sooner had sb done than sb did。==前半截倒装用过完，后半截不倒装用一般过去==。
- when 表"突然、正在那时"：前面是过去进行 / was about to do 等过去时态，when 从句固定用一般过去。

## 5. 从句里的时态

- 宾语从句：主过从必过；例外是真理永一现（He said that the earth goes around the sun.）。
- 定语从句起分隔作用时，谓语要找准==主句真正的主语==，不是从句主语。
- 地点 / 时间介词短语置句首用完全倒装，谓语看后面真正主语：Under the main road run power lines.

# 四、非谓语动词：完整形式表

## 1. 主被动 × 先后序

解题两步：① 看非谓语与逻辑主语的主被动；② 看它与主句谓语的先后。

| | 之前（先于主句） | 同时 | 之后（晚于主句） |
| --- | --- | --- | --- |
| 主动 | having done；to have done | doing；to be doing | to do |
| 被动 | having been done；to have been done；done | being done | to be done |

## 2. 介词 to 还是不定式 to

- 表目的 / 结果 → 不定式符号，加 to do。
- 表对象 / 方向 → 介词 to，加 doing：get used to、be opposed to、devote to、contribute to、lead to、stick to、pay attention to。

## 3. 三个易错成分（定、状、补）

- 状语：不定式表目的或 ==only to do 出乎意料的结果==；分词表伴随 / 方式 / 因果。
- 补语：ask / allow / advise sb to do；感官 see sb do / doing，see sth ==done==（被做）；使役 have sb do，have sth done（让某事被做）。
- 定语：后置定语要分清主被动，看非谓语与所修饰名词的关系。

## 4. 过去分词的三个用法

> [!warning] done：被动、完成、状态，符合一个即可
> 表状态是最容易忽略的：be seated（坐着）、be lost（迷路）、be stuck（被困）、be married（已婚）。这些理解成过去分词表状态，比理解成被动更准确。

## 5. having done / having been done

- 用 having 是因为有明显的==时间先后==：Having worked hard all day, I went to bed early.
- 或有==因果关系==：Having been seriously injured, he was rushed to hospital.
- 直接用 doing 体现不了先后，用 done 又丢了主动，所以必须用 having。

## 6. 独立主格与 with 复合结构

- 当非谓语的逻辑主语与句子主语不一致时，用"独立主语 + 非谓语"：Bats can live long, some (bats) having a lifespan of fifty years.
- 前面加 with 就是 with 复合结构，形式完全一样。这是逻辑主语不等于句子主语的唯一例外。

## 7. 动名词复合结构

在动名词前加动作执行者（名词所有格 / 形容词性物主代词）：I appreciate ==your== helping me. 加了执行者不影响动名词本来的 doing 形式。

# 五、虚拟语气

## 1. if 条件句

| | 主句 | 从句 |
| --- | --- | --- |
| 对现在 / 将来虚拟 | would/could/should/might + do | did / were（系动词一律 were，无 was） |
| 对过去虚拟 | would/could/should/might + have done | had done |

挖在主句看主句，挖在 if 从句看从句。

## 2. 含蓄条件句

没有 if，但用 with / without / but for / otherwise 表达"如果"：

- 碰到含蓄 → 过将完：would have done。
- 如果有现在 / 将来时间提示 → 过将：would do（Without electricity, life would be quite different today.）。

## 3. 三个特殊情况

- 碰到 but：半真半假，but 后面是真的不用虚拟，前面假的才虚拟（I would have helped you, but I was busy.）。
- 碰到错综：一分为二，主句、从句按各自时间分别判断（If John hadn't lost his job last month, he would go abroad next week.）。
- if 省略：去掉 if，助动词提前（Were I you…；Should he come…）。

## 4. should 类：I drop caps

> [!tip] 口诀 I drop caps
> Insist、Demand、Require / Request、Recommend、Order、Propose、Command、Advise、Prefer、Suggest。
> 这些词后的从句用 (should) do，==should 可省、动词原形不能省==。

三句注意：

- 分清主被动：被动是 (should) be done，be 动词不能丢。
- 主宾表同都一样：主语 / 宾语 / 表语 / 同位语从句都用这套虚拟。
- 一头一尾属特殊：insist 和 suggest 所加内容为真（已发生、或确实如此）就不虚拟，为假 / 未发生才虚拟。suggest 表"建议"用虚拟，表"暗示、表明"不用。

## 5. 退一步类：wish / would rather

把时态往前推一格：对现在用 did/were，对过去用 had done，对将来用 would do。would rather 没有 would do 这一格，对将来也推到过去。

# 六、完形：啦啦队长救小孩

这讲完形是花车游行上啦啦队女孩用海姆立克法救起被糖卡住的两岁男孩。

- 解题口诀：名词找同类、动词看搭配、形副标正负、带本意、借对象、连逻辑。

# 七、这讲的自检要点

- 动词五考点先分清，谓语走"时语数"三步，非谓语走"主被动 + 先后"。
- 非谓语完整形式表要能默写，尤其完成形式 having done / having been done。
- 过去分词三用法别漏了"表状态"；having 用于先后或因果。
- 虚拟语气全国卷语法填空基本不考，但要能在阅读、完形里看懂，并敢写进作文。
- 这讲题量大，重点是把讲义上的语法填空做熟——会判断但写不对仍不得分。
