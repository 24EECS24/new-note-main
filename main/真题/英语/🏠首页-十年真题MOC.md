# 📚 河南专升本《公共英语》十一年真题题库（2016—2026）

> [!info]- 资料说明（点开）
> - 每年含两篇笔记：**真题试卷**（无答案，可模考）与**参考答案及详解**（答案高亮、解析可折叠）。
> - 河南省教育考试院**不公布官方真题与标准答案**，题目与答案整理自库课、天任、耶鲁、豫升、好老师升学帮、希赛等机构考后回忆版及 PDF，均尽量两家以上交叉核对；英文阅读/完形篇章逐字转录校对 OCR。分歧处以橙色「⚠ 答案存疑」框标注，未擅自取舍。
> - **2021 年题型改革**：2016—2020 为旧大纲（Part I 词汇与结构 40 单选 + 完形 + 阅读 + 翻译 + 改错 + 写作）；2021—2026 为新大纲（阅读 4 篇 + 完形 + 阅读判断 + 翻译[译选/选词/汉译英] + 改错 + 写作）。每年板块以原卷实际为准。2026 年为考后机构回忆版初版，持续更新中。
> - 作文为**参考范文**、翻译为**参考译文**，均已注明「非官方标准答案，仅供参考」。
> - 每篇笔记底部折叠嵌入了原版 PDF（出版级 XeLaTeX 重排，英文衬线 + 中文衬线）。用 Obsidian「打开文件夹作为仓库」选择本文件夹即可。
